# 办法 / 规定（印发型通知的主件·法规体例）

印发型通知的主件常是"办法/规定/实施细则/规程"——**法规体例**：第一章/第一条，分
**总则—分则—附则**三段。作为 `attachment_title`/`attachment_body` 渲染（自动换页 + 方正小标宋二号居中标题）。
> 主件标题**不带书名号**（书名号只用在通知壳的承启句里）；`第一章/第一条` 渲染器自动套版。

## 结构（总则 — 分则 — 附则）
```
{办法名称}                          ← 主件标题（不带书名号）

第一章 总  则
第一条  〔目的+依据〕为了{目的}，根据《{上位法}》，结合本市实际，制定本办法。
第二条  〔适用范围〕本市行政区域内{事项}，适用本办法。
第三条  〔基本原则〕{事项}应当遵循{原则}。
第四条  〔主管部门〕{部门}负责{职责}；{相关部门}按职责配合。

第二章 {核心制度一}
第五条  ……      ← 分则是血肉：把制度展开到可执行（标准/金额/期限/流程/分档），别停在原则

第三章 {核心制度二}
……

第N章 附  则
第X条  〔施行+有效期〕本办法自{X年X月X日}起施行，有效期5年。
第X条  〔废止衔接〕《{旧办法名}》（{旧文号}）同时废止。
第X条  〔解释机关〕本办法由{部门}负责解释。
```

## 必带条款（缺一即不合规）
- **第一条**：制定目的 + 依据（"根据《…》"）+ "结合本市实际，制定本办法"。
- **适用范围**：本办法管什么、管谁。
- **附则·施行日期 + 有效期**："自{X年X月X日}起施行，有效期5年"（规范性文件一般 5 年）。
- **废止 / 衔接**（修订或重新发布时**必须**，上次最易漏）：
  - "《{旧办法名}》（{旧文号}）同时废止"；
  - 过渡条款："本办法施行前已{作出决定/取得许可}的，继续沿用原规定办理"。
- **解释机关**："本办法由{部门}负责解释"。

## 章条体例
- 章：`第一章 总  则`（"总则/附则"二字间空两格是惯例）—— 渲染器自动**居中黑体三号**。
- 条：`第一条  〔内容〕`（条号后空两格接正文）—— 仿宋三号、首行缩进 2 字。
- 条下分项：`（一）（二）`；再细 `1. 2.`。

## 起草深度（对标真实件，这是和"条例缩写"的分水岭）
真实办法动辄 **40+ 条**，每条含**可执行细节**：具体金额、时间期限、面积/比例、分档处理、
明确到部门。骨架好写、**血肉难补**——具体数值/标准若无依据，标 `〔待核：参照{某文件}〕`，
**不要编看似精确的数字**。要写实，须检索同领域已发布办法与上位法（知识库就绪后用 `kb_search`）。

## 真实范例（结构·穗府办规〔2026〕6号 房屋征收与补偿实施办法）
五章四十八条：
- 第一章 总则（部门职责 / 委托征收实施单位）
- 第二章 征收决定（七种公共利益情形 / 社会稳定风险评估 / 征收公告九项内容）
- 第三章 补偿（货币 vs 产权调换 / 搬迁费每户≥5000元 / 临时安置3个月 / "住改商"按1987·1997·2001节点分70%·60%·50%）
- 第四章 征收实施（补偿协议 / 强制执行）
- 第五章 附则（自印发起施行·有效期5年 / 废止穗府规〔2021〕2号 / 区政府可制定操作细则）

> 对照可见：真实件每条都"落到钱、落到天数、落到部门"；AI 初稿若只到"应当给予补偿"
> 这种原则层，就是差距所在——结构能给满，数值靠检索 + 人工核。
