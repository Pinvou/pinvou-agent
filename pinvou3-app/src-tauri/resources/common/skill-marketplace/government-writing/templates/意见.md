# 意见（实施意见）

用途：就某项工作提出指导思想、目标、举措、保障。与通知的区别：**通知是壳，意见是主件**；意见自身分"总体要求—分项举措—组织保障"三段式。

## 骨架
```
{发文机关}关于{事由}的（实施）意见
{机关简称}〔{年}〕{序号}号

{主送机关}：
　　为{目的}，{依据/背景，可多句}，经{市人民政府／市委、市政府}同意，现提出如下意见。

　　一、总体要求
　　（指导思想 + 基本原则 + 主要目标——常含量化指标与时间节点）

　　二、{第一组举措主题}
　　（一）{具体举措}。{展开}。（牵头单位：{…}；配合单位：{…}）
　　（二）……

　　三、{第二组举措主题}
　　……

　　{末章}、加强组织保障
　　（落实机制、经费、督查、宣传）

{发文机关}
{成文日期}

公开方式：主动公开
{发文机关}秘书处　{印发日期}印发
```

## 结构要点
- **引出句固定**：`为…，…，经市人民政府同意，现提出如下意见。`（"实施意见"则收"现提出如下实施意见。"）
- **"一、总体要求"几乎必有**，内含指导思想 + 目标（量化 + 年限），如"到2027年…达185万人"。
- 分项举措：`一、`（主题层）→`（一）`（具体条）；**每条末尾挂分工** `（牵头单位：…；配合单位：…）`——这是意见类区别于普通通知的标志性写法。
- **末章固定为"加强组织保障"**类收口段。

## 真实范例（结构骨架·穗府办〔2025〕7号 高技能人才队伍建设实施意见）
- 一、总体要求（含"到2027年…高技能人才达185万人""新增培育先进制造业技能人才10万人次"等量化目标）
- 二、构建高技能人才多元培育格局　（一）加强高技能领军人才培养…（牵头单位：市人力资源社会保障局…）
- 三、深化技能人才评价机制改革
- 四、完善技能导向的使用机制
- 五、营造高技能人才发展的良好环境
- 六、加强组织保障

## 采集要素（缺则一次问全）
发文机关 · 字号性质 · 事由（加强/推进/促进…）· 目的与背景 · 量化目标与年限 · 主要举措分组 · 各举措牵头/配合单位 · 成文日期
