# Tencent Meeting tmeet-skill

This bundled skill is synced from the Tencent Meeting CLI connector package already present in the local WorkBuddy connector marketplace:

`C:\Users\123\.workbuddy\connectors-marketplace\connectors\tmeet\skills`

It is gated by the Pinvou Tencent Meeting CLI connector and is only extracted into the runtime skills directory when the user has connected `tmeet` and has not disabled the Tencent Meeting skill.
