# design-principle.consulting.md · 商务咨询

## 1. 风格 DNA

- **Action Title 优先**：正文页主标题必须是完整结论句，不能只写“市场分析”这类关键词。
- **Navy 权威感**：`#061F32` 主导全篇；颜色少、装饰少、信息强。
- **结构图优先**：能用结构图讲清的内容，优先走信息结构图，不堆卡片。
- **左对齐纪律**：标题、正文、图表说明默认左对齐；禁居中海报感。
- **数据 + Source 可信**：数据页、正文页、结构图页必须有 Source / Footnote。
- **无衬线商务感**：Arial + 中文黑体；禁衬线、书法、艺术字。
- **极简不是空**：留白 25–40%，内容必须承担判断、论据、结论。

## 2. 母版与版面骨架

画布：1280×720；页面左右 padding 49–60。

| 区域 | 范围 | 规则 |
| :-- | :-- | :-- |
| A 页眉 | y 0–44 | 可选，仅右上 14–16px 灰色章节进度；禁彩色竖条 |
| B 标题块 | y 44 起，高度自适应 | Action Title 32–40px Bold，左对齐；**顶部紧贴页面上沿（起始 y = 44），禁在标题上方留大段空白**；A 页眉为空时标题也从 y = 44 起，不得下移到 72；高度随标题行数自适应——单行约 60px（底 ≈104）、双行约 90px（底 ≈134）；底部 1px 黑线紧随标题底线下 8–12px 作 B/C 分割。单页标题建议 ≤2 行（≤30 字） |
| C 内容区 | 自 B/C 分割线下 12px 起 至 y 660 | 正文、图表、结构图、卡片；上沿不写死，跟随 B 区实际底线，避免长标题压内容或短标题留大空 |
| D 页脚 | y 660–700 | 左 Source + Footnote 14–16px 灰两行；右页码 `NN` 14px 灰 |

省略规则：封面、章节扉页、系统标记可省 A/D；目录保留右下页码；前言、正文、模型、图表、结构图必须完整遵守。

## 3. 色彩与字体

### 色彩

| 角色 | hex | 用途 |
| :-- | :-- | :-- |
| Navy 主色 | `#061F32` / `#062032` | 章节底、主框架、重点色块 |
| 皇家蓝 | `#001965` | 图表第二蓝、层级色 |
| Cyan | `#08A6F6` | 关键点缀、客户/重点标记；单页 ≤5% |
| 浅蓝 | `#99BDED` | 图表第三档、辅助色阶 |
| 暗红 | `#5A0E13` | 涨色 / 警示，仅数据或风险 |
| 绿色 | `#177B57` | 跌色，仅数据涨跌 |
| 橙色 | `#F47B39` | 中等风险，少量 |
| 中性灰 | `#E7E6E6` / `#808080` / `#44546A` | 表底、脚注、边框 |
| 背景 | `#FFFFFF` | 内页主底 |

配色比：Navy 系 20–35%，白底 ≥50%，中性灰 ≤15%，强调色合计 ≤8%。禁金色、中国正红、朱砂红、紫粉黄品红、彩虹色、阴影、发光、3D。

### 字体

字体家族：`Arial, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`。

| 层级 | px | 字重 | 用途 |
| :-- | :-- | :-- | :-- |
| 章节编号巨字 | 160–320 | Bold | 仅章节扉页 |
| 封面主标 | 60–96 | Bold | 封面 |
| KPI 大数 | 72–120 | Bold | 数据页 |
| Action Title | 32–40 | Bold | B 区固定 |
| 副标 / 卡片小标 | 24–30 | Bold | 次级标题 |
| 正文 | 22–28 | Regular | 段落（大字正文，硬下限 ≥22px） |
| 数据标签 | 16–18 | Regular | 图表标签 |
| Source / Footnote / 页码 | 14–16 | Regular | 页脚 |

单页字号种类 ≤5（章节扉页除外）；**正文硬下限 ≥22px**；字号梯度必须分明，相邻层级拉开 ≥6px，刻意制造大字对比。

## 4. 信息密度与可读性

| 类型 | 下限 |
| :-- | :-- |
| 封面 | 主标 + 副标 + 公司名/Logo + 时间，≥20 字 |
| 目录 | 3–8 条，每条含编号、章节名、摘要，总字数 ≥80 |
| 章节扉页 | 巨字编号 + 章节标题 + 英文副标，≥14 字 |
| 执行摘要 | 三栏 Context / Complication / Resolution，总字数 ≥160 |
| 单主题 | 正文 + 主视觉，≥120 字，图 ≥30% |
| 卡片组 | 每卡 ≥40 字，3 卡合计 ≥120 |
| 思维模型 | 模型名 + 所有维度，≥160 字，SVG ≥50% |
| 数据图表 | 主图 ≥50%，洞察 50–90 字 |
| 信息结构图 | 结构图 ≥70% C 区 + Source |

> **大字优先原则**：本风格走大字冲击路线，正文字号下限优先级 > 字数下限。当大字号导致内容塞不下时，应**精简文案、合并页面**，而非缩小字号去硬塞字数。字数下限是"够用即可"，不是"越多越好"。

可读性硬线：文字对比度 ≥4.5:1；浅灰底必须用黑字或 Navy 字；Cyan 底禁白字；卡片填充率 ≥75%；卡尾 y 差 ≤16px。正文行高 1.4–1.5（大字号下勿用 1.7，否则行距过空）。

## 5. 配图与视觉元素

### 配图

| 等级 | 用途 | 规则 |
| :-- | :-- | :-- |
| L1 主视觉 | 摄影或数据可视化 | C 区 ≥40%；全篇二选一，不混用 |
| L2 支撑图 / icon | 卡片头、流程节点 | 图 ≥280×180；icon 24–48px |
| L3 母版徽标 | 统一角标 | ≤64×64，仅 D 区左下 logo 位 |

L1 视觉类型二选一：A 摄影类（去饱和 Navy 冷调）；B 数据可视化类（图表 + 线性 icon）。禁插画、3D、合成海报、红金图、城市落日实景。

Icon：仅线性单色，1.5–2px 描边，Navy 或 Cyan；禁彩色填充、emoji、渐变、卡通。

## 6. 页面类型规则

### ① 封面

- 满 Navy 底，或白底 + Navy 主色块占左 1/3–1/2。
- 主标 60–96px Bold，左对齐；副标紧贴主标下方。
- 必备：主标、副标、公司/Logo、时间/版本；禁满版照片、金红剪影、烟花飘带、居中海报、巨字水印。

### ② 目录

- 纯白底；主标左上 26–32px Bold Navy。
- 3–4 项单行 N 列；5–6 项 2×3；7+ 项 2×4。
- 条目 = 大编号 + 章节名 + 摘要；禁圆球编号、书法繁体、单列大目录。

### ③ 章节扉页

- 满铺 `#062032`；左侧 160–320px 低透明白色巨字编号。
- 右侧章节标题 40–48px 白字，英文副标 20px 浅灰。
- 禁图片、渐变、金色、Cyan、装饰线、章节页码。

### ④ 执行摘要

- 纯白底 + Navy 标题 + 三栏并列。
- 三栏：Context / Complication / Resolution，每栏 80–120 字。
- 可用 0.5px 分隔线和 2px Navy 顶线/竖条；**顶线/竖条必须紧贴栏标题（间距 ≤8px），不得悬空在标题上方留出大片空白方框**；竖条仅作标题的小装饰，长度 ≈ 标题文字高度，禁占独立高度块。禁图标矩阵、首字下沉、引文装饰。

### ⑤ 正文

- ⑤a 三栏卡：3 卡水平并列，icon + 标题 + 正文，每卡 ≥60 字。
- ⑤b 四/六栏小卡：只放 icon、标题、短说明，用于要点密集页。
- ⑤c 时间轴：横向 4–6 步，1px Navy 主线 + 统一节点。
- ⑤d 大图配文：图 50–60%，右侧 3 Bullet + 数据。
- ⑤e KPI：4 个 KPI 卡，大数字 + 单位 + 同比 + 一句说明。
- ⑤f 对比 VS：左右对照，禁红绿装饰对比。
- ⑤g 关键词矩阵：2×2 / 3×3，细灰线分隔。
- ⑤h 综合复杂：战略地图 / 实施计划 / 多栏复合；若核心是结构图，改走 ⑨。

**卡片排布纪律（强约束）**：
- 卡片数必须与列数匹配，**禁止末行残缺留坑**（如 5 卡排 3 列 → 3+2 缺 1，不允许）。按卡数选列：3/6/9 卡→3 列；4/8 卡→4 列（或 2×2）；5 卡→改为 5 列单行、或 2+3 上下贯通、或合并为 4 卡/拆为 6 卡，使每行填满。
- **末行不满时**：要么补内容凑满整行，要么调整列数让各行等宽填满，要么将剩余卡横向拉宽占满该行宽度；禁止留出与卡同宽的空位。
- 同组卡片**等宽等高**，行间 gutter 统一；多行卡组各行左右边界对齐。

正文页必须：完整母版、Action Title、Source、Footnote、页码；装饰只允许浅灰线、Navy 上边框/竖条、线性 icon。**装饰性竖条/上边框必须紧贴所修饰的标题或内容（间距 ≤8px），禁悬空、禁单独占一块空高度方框**——若一根短竖条与下方文字之间出现明显空白带，即为缺陷。

**C 区整体撑满（强约束）**：正文页所有内容（卡片/列表/图表）的累计高度应填满 C 区可用高度的 ≥85%，纵向不得只占上半部而让下半大片留白。内容不足时应：增大卡片高度并补充每卡内容、增大行距与卡距均匀铺满、或减少页面数把内容合并；禁止"内容挤在上半、下半空荡"。左右两栏（如左卡组 + 右列表）底部应大致对齐，禁一栏长一栏短留出大段空白。

### ⑥ 思维模型

- 同一视觉模板成套；模型名 + 中央示意图 + 右侧维度说明。
- 中央示意图的**形状/连线**可用 SVG，但**图内文字必须是独立可编辑文本，禁烤进 SVG**（见 §⑨ 文图分离）。
- 单色阶 Navy 4–5 阶；线条 1–2px；禁彩虹色、纹理、3D。

### ⑦ 数据图表

- 白名单：柱、折、瀑布、散点、树状、Mekko、2×2 矩阵。
- 黑名单：立体饼、立体柱、3D 散点、雷达、螺旋。
- 必备：Action Title、主图 ≥50%、洞察 80–150 字、Source/Footnote、单位标注。

### ⑧ 系统标记

- 母版省略；白底灰字一行；交付前删除。

### ⑨ 信息结构图

咨询风核心，建议占全篇 ≥20%。结构图占 C 区 ≥70%，标题必须陈述结构图结论。

通用约束：

- 节点形状：矩形、圆角矩形（≤4px）、圆、椭圆、三角、箭头、chevron、平行四边形、梯形。
- 线条：直线或直角折线；禁曲线连接；主框架 1–2px，分支 0.5–1px。
- 配色：Navy 单色阶 + 少量 Cyan；禁彩虹、阴影、3D、装饰背景。
- 字号：节点标题 22–28px Bold，说明 16–18px，标签 14–15px。
- **文图分离（强约束）**：结构图的**形状层**（矩形/chevron/箭头/连接线/色块/坐标轴）用 SVG 或原生图形组件绘制；但**所有文字（节点标题、说明、数据、标签、轴名）必须是独立的可编辑文本元素，禁止烤进 SVG 路径**。即——结构图 = 「SVG 形状骨架」叠加「真实文本层」，而非「一整张含文字的 SVG 图片」。原因：烤进 SVG 的文字无法编辑/选中/复制，不受 §3 字号体系管控，渲染易糊。同理禁止整块流程图/价值链/房屋图导出为单张 PNG/SVG 位图。

12 个常用子版式：

## 7. 最终硬闸门

出现以下任一情况必须返工：

1. 正文页 Action Title 不是完整结论句，或 ≤8 字关键词。
2. ⑤/⑥/⑦/⑨ 缺 Source / Footnote / 右下页码。
3. B/C 分割线缺失、非 1px 黑线；或 B 区起始 y 各页不统一（应固定 =44）；或标题上方留大段空白（标题距页面上沿 >48px，如误用 72px，造成顶部空隙）；或分割线未紧随标题底线（与标题间距 >16px）。
4. 字体家族不是 Arial + 中文黑体，或出现衬线 / 书法 / PNG 字图 / 文字烤进 SVG（结构图、流程图、价值链、思维模型的文字必须为可编辑文本层，禁整块含字 SVG/位图）。
5. 配色超过 Navy / 皇家蓝 / Cyan / 警示色 + 中性灰范围。
6. 金色、朱砂红、中国正红、紫粉黄品红、彩虹色出现。
7. 单页字号种类 >5，或正文 <22px，或相邻层级字号差 <6px（梯度不分明 / 大字感不足）。
8. 文字对比度 <4.5:1。
9. L1 摄影类与数据可视化类混用。
10. 结构图可用却堆卡片；全篇 ⑨ 占比明显不足。
11. ⑨ 使用曲线连接、心形/云朵/星形等非白名单形状。
12. 图表出现 3D、雷达、螺旋或装饰背景。
13. 任意页字数低于下限 70%。
14. 占位文未清零。
15. 装饰性竖条 / 上边框 / 顶线悬空，与所修饰的标题或内容之间留出明显空白带（间距 >8px），形成"短线 + 空方框 + 文字"的脱节布局。
16. 卡片组末行残缺留坑（卡数与列数不匹配，如 5 卡排 3 列留 1 空位），或同组卡片不等宽等高 / 多行边界不对齐。
17. 正文页内容未撑满 C 区（累计高 <85% 可用高），下半部大片留白；或左右两栏底部高度悬殊留出大段空白。
