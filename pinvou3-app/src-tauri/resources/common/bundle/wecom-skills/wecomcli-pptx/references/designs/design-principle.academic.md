# design-principle.academic.md · 学术风

## 1. 风格 DNA

- **学术可信**：蓝白浅灰为基底，表达研究、证据、方法、结论，不做营销海报。
- **撑满优先**：内容页 C 区元素累计高度 ≥96% 可用高；留白不是主要视觉手段。
- **证据化配图**：L1 必须是论文截图、真实实验/场景摄影、流程 SVG、显微/医学图之一。
- **卡体克制**：常规卡用浅底淡描边；深蓝实色卡只作语义凸显，限频使用。
- **层次清楚**：正文页至少有标题、主体卡/图、底部结论或数据锚点。
- **色彩受控**：宝蓝主导，红/黄只作重点或警示，金色为 0。
- **图文都要有内容**：不得用大留白、空卡片、装饰图凑版面。
- **公式与学术真实**：页面中出现的公式、定理、数据、结论必须真实且有据可查，来源于真实论文、教材或权威资料；禁止杜撰公式、虚构数据或编造引用，关键公式与数据应可追溯到出处。

## 2. 母版与版面骨架

画布：1280×720。安全边距：左右 40。C 区背景只允许 `#FFFFFF` / `#F7F9FC`。

| 区域 | 范围 | 规则 |
| :-- | :-- | :-- |
| A 页眉 | A1=104 / A2=48 / A3=72–88 | 全篇锁定一种；内容页默认 A3 |
| B 标题块 | A2 模式 y 48–156 | 主标 32–40px Bold 深蓝；A3 模式并入页眉 |
| C 内容区 | A2 y 148–660；A1/A3 y 80–660 | 内容页必须铺满 1200px 宽、≥476px 高 |
| D 页脚 | y 660–700 | 左 logo/单位 14px 灰；右页码 14–16px 深蓝 |

页眉模式：

- A1：深蓝实色顶条，严肃答辩用。
- A2：浅顶条 + 深蓝分隔线，仪式段 / 极简学术用。
- A3：深蓝顶条 + 低透明校园/城市线稿，内容页默认。

封面、目录、章节扉页、感谢页可省略 A/D；其余页必须遵守母版。

## 3. 色彩与字体

### 色彩

| 角色 | hex | 用途 |
| :-- | :-- | :-- |
| 主蓝 | `#1E4FA8` | 顶条、编号、强调 |
| 藏蓝 | `#0E3F8C` | 深底、章节、重点 |
| 浅蓝 | `#E8EFF8` / `#F0F5FC` | 卡片底、表头浅底 |
| 中蓝 | `#3D7BD9` | 链接、描边、图表第二色 |
| 警示红 | `#D9534F` | 关键词、异常、风险；单页 ≤3% |
| 数据黄 | `#FFC107` | 图表第二序列、核心金句；单页 ≤3% |
| 文本 | `#1A2230` / `#4A5568` / `#8B97A8` | 主 / 副 / 辅助 |
| 线框 | `#D6DCE5` / `#E5E7EB` | 描边、表格线 |
| 背景 | `#FFFFFF` / `#F7F9FC` | 主背景 |

配色比：蓝族 35–55%，白底 30–55%，浅蓝 0–35%，红+黄 ≤5%，金色 = 0。禁紫粉玫红、橙绿大色块、彩虹渐变、纯黑大底。

### 字体

| 层级 | px | 字重 | 用途 |
| :-- | :-- | :-- | :-- |
| 封面英文长 title | 48–64 | Bold Serif | 学术论文式标题 |
| 封面中文主标 | 60–96 | Bold | 封面 |
| 章节大数字 | 120–320 | Bold | 章节扉页 |
| A3 / B 区主标 | 32–40 | Bold | 每页主标题 |
| 卡内标题 | 24–30 | Bold / 600 | 卡片小标 |
| 正文 | 22–28 | Regular | 段落 |
| 表格 | 18–22 | Regular / Bold | 表头、表体 |
| KPI 巨数字 | 72–120 | Bold | 数据强调 |
| 注解 / 页脚 | 14–16 | Regular | 单位、来源、页码 |

字体家族 ≤2 套：思源黑为主；思源宋 / Times 仅用于封面英文长标题或引文。禁楷体、行书、毛笔、艺术字、空心字、3D 字。

## 4. 信息密度与可读性

- 内容页 C 区累计高 ≥476px，宽 =1200px；元素不得集中在中央 60% 区域。
- 卡片填充率 ≥80%；高 ≥380px 卡正文 ≥130 字，高 ≥480px 卡正文 ≥170 字。
- 单行多卡等高；卡尾数据、标签、金句必须锚底；兄弟卡高差 ≤8px。
- 卡内 padding：上下 16，左右 ≥20；正文必须允许软换行，禁止溢出。
- 文字对比度 ≥4.5:1；蓝底放白字，白底放深蓝 / 深灰。
- 正文页至少复用 3 类组件，至少 4 种文字修辞，至少 3 个内容层次。
- 仪式段留白 ≤35%；内容页禁用大留白作为风格。

### 页面信息下限

| 类型 | 下限 |
| :-- | :-- |
| 封面 | 中英标题 + 单位 + 汇报人 + 时间，≥30 字 |
| 目录 | 主标 + N 条目，≥30 字 |
| 章节扉页 | 大数字 + 标题 + 子要点，≥60 字 |
| 前言 | 单段长文 ≥220 字 |
| 正文卡片页 | 每卡 ≥110 字或按内容选择更紧凑版式 |
| 大图配文 | 文字 ≥220 字，图 ≥50% |
| 数据图表 | 主图 ≥50%，洞察 ≥100 字，≥1 个关键数字 |
| 表格页 | 表格 ≥70% C 区 + 结论 |

## 5. 配图与组件

### 配图

| 等级 | 用途 | 规则 |
| :-- | :-- | :-- |
| L1 主视觉证据 | 论文截图 / 真实摄影 / 流程 / 显微图 | 双栏 ≥35%，大图 ≥50% |
| L2 支撑图 | 设备、头像、缩略证据 | ≥240×160；头像 ≥120×120 |
| L3 LOGO / 图标 | 学校、章节、流程 | ≤64×64，LOGO ≤180×60 |

全篇 L1 视觉类型必须统一；单类占比 ≥60%。禁 3D、卡通、二次元、营销插画、装饰渐变大图。

### 组件族

- **标签 / 编号**：浅蓝药丸、深蓝编号方块、警示红药丸、黄色高亮标签；红黄受配额限制。
- **标题 / 金句条**：深蓝标题条、底部强调条、核心金句条；核心金句条单页 ≤1，全篇 ≤4。
- **卡体**：默认淡描边卡 TC-6；凸显单卡用柔和阴影卡；深蓝实色卡单页 ≤1、全篇 ≤3、多卡页禁用。
- **流程连接**：节点串、胶囊步骤、公式连接、箭头；用来把多卡页串成整体。
- **数据强调**：KPI 三联数、表格高亮、圆环进度、引文符号块。

卡片填充只允许白 / `#F7F9FC` / `#F0F5FC` / `#E8EFF8` 或低纯度浅色；禁渐变填充作卡背景。

### 卡内五段骨架

常规正文卡优先包含：S1 标题条、S2 引导句、S3 主体正文、S4 关键数据/引文、S5 尾部标签。S1/S3/S4 必填，S4 锚底；信息太少时改版式，不用空白撑高。

## 6. 页面类型规则

### ① 封面

- 优先采用学校 / 机构学术封面：LOGO、中文主标、英文长 title、副标、汇报人、时间。
- 可选深蓝顶条、中央论文式标题、底部信息条；禁党政红金、印章、烟花、金装饰、人物大头照。

### ② 目录

- 3–6 个条目；编号、中文标题、摘要清晰分组。
- 可用左深蓝栏、胶囊导航或编号条；禁圆球编号、书法繁体数字、英文比中文更抢眼。

### ③ 章节扉页

- 全篇锁定一种样式；大数字 + 标题 + 2–4 个要点。
- 禁满版蓝红金、PART 02 字样泛滥、与封面雷同。

### ④ 前言

- 完整母版；C 区放一段 ≥220 字长文。
- 可用首字下沉和底部蓝色强调句；禁多卡、分栏、大主视觉。

### ⑤ 正文

- 5a 双栏对照：两张淡描边卡 + 中央连接 / VS / 箭头 + 底部结论。
- 5b 三栏并列：三张同款卡，允许一张凸显；禁多张深蓝实色卡。
- 5c 流程时间轴：4–6 步，节点 / 胶囊 / 横线统一。
- 5d 大图配文：图 50–60%，文字区含标题、证据说明、结论条。
- 5e 数据强调：KPI、圆环或三联数 + 注解 + 结论。
- 5f 关键词矩阵：2×2 或 2×3，编号 + 标题 + 说明。
- 5g 综合复杂：用于技术路线、实验设计、研究框架；至少 5 类组件。

多卡页必须有双重锚定：一种物理连接（节点串 / 箭头 / 共享外框）+ 一种共享锚点（标题条 / 底部强调条）。

### ⑥ 思维模型

- 中央 SVG 结构图 + 各维度说明；节点圆角矩形或正圆。
- 多张模型页必须同字号、同卡体、同色阶、同图标风格。

### ⑦ 数据图表

- 主图 ≥50% C 区；上方必须有 L0 引导问题条。
- 配色：主蓝、对比黄 / 中蓝、警示红、中性灰。
- 表格：深蓝表头、浅斑马或浅高亮，关键格可浅红 / 浅黄。

### ⑧ 感谢页 / 系统标记

- 感谢页延续封面或顶条体系；禁烟花、金装饰、印章。
- 系统标记一行灰字，交付前删除。

## 7. 最终硬闸门

出现以下任一情况必须返工：

1. 内容页未撑满：C 区累计高 <476px 或留白明显过大。
2. C 区使用深色实底或高饱和彩色实底。
3. 红+黄 >5%，金色出现，或使用禁色。
4. 字号低于下限，正文 <22px，卡内标题 <24px。
5. 卡片缺 S1/S3/S4，或卡内连续空白带明显。
6. 深蓝实色卡超限，或多卡页使用多张深蓝实色卡。
7. 卡填充不符合低纯度规则，或渐变作卡背景。
8. 正文页组件 <3 类、修辞 <4 种、层次 <3 层。
9. 多卡页缺双重锚定，页面呈散碎卡片堆。
10. L1 视觉类型混杂，或配图为 3D / 卡通 / 营销插画。
11. 文字溢出卡片、断词异常、对比度 <4.5:1。
12. LOGO / 页码 / 顶条模式全篇不一致。
13. 数据图表缺主图、洞察或关键数字。
14. 占位文未清零。
15. 公式、定理、数据或引用系杜撰、虚构或无据可查，关键公式 / 数据无法追溯到真实出处。
