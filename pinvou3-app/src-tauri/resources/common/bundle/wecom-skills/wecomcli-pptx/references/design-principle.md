## 文件层级声明
- 本文件是设计的**通用法则**——所有项目必读，所有硬门禁（密度、容器填充率、视觉锚点、色彩面积分配等）默认生效；未命中领域分支时即为本项目的最终边界。
- `designs/` 是本文件的**领域特化分支**——每一份 `design-principle.<id>.md` 是某一种成熟视觉文化（academic / consulting / redgold）的"风格知识包"。每份分支文件内容**分两层**：
  - **结构层**：版式分类（①②③…）、字号阶梯比例、色彩面积分配比例、装饰白名单**结构**、自检与返工触发条件、留白/密度上下限框架——这是该视觉文化的工程化骨架，**对内容相似的项目仍具普遍指导价值**
  - **常量值层**：默认色板 hex、默认字体家族名、默认装饰具体项、默认场景标签语义引用——这是该视觉文化在"标准场景"下的填空答案，可被 query 改写
- Step4 进入设计阶段后，先用 [create-from-scratch.md](create-from-scratch.md) Step4 §风格场景适配表 做关键词路由，结果分**三态**：
  - **完全命中**（命中关键词 ≥ 1 ∧ 禁用词 = 0）→ 分支**结构层 + 常量值层**与本文件**共同构成本项目设计宪法**，两份均需完整加载、整体执行
  - **软降级命中**（命中关键词 ≥ 1 ∧ 禁用词 ≥ 1，即内容相似但场景层有偏离）→ 分支**结构层继续生效**（视为本项目结构宪法），**常量值层失效**，由用户 query / `STORY.md` 推导改写填空；这条路径**比 universal-only 更优**，因为分支结构骨架仍是该相似领域的最佳工程化沉淀，丢掉它退化到通用法则等于丢失设计纵深
  - **多行命中** → 取命中关键词最多的一行为主分支
  - **全表无命中**（任意行命中关键词数 = 0）→ 仅基于本文件与 `STORY.md` 原创设计稿（universal-only）
- 通用法则与命中分支冲突时的解决规则（优先级链：**用户显式指令 ≻ 命中分支结构层 ≻ 通用法则**）：**① 用户显式指令优先**——用户在 query 中以具体值/具体名称给出的工程化指令（hex 码、命名色、字体家族、页数、比例、装饰增减、量化密度偏好）覆盖分支常量值层与通用法则的对应缺省值；覆盖**仅作用于被显式指定的常量值**，分支的结构层（比例、阶梯、版式分类、装饰白名单结构、自检）继续生效。**② 同向冲突（同维度紧/松对比）以更严格者为准**（例：通用强调色 ≤ 10% vs 分支 ≤ 5% → 取 5%）；**③ 正交冲突（一边上限、一边下限）以领域分支为准**（例：通用「常规页留白 ≤ 35%」 vs 某分支「内页留白 ≥ 40%」 → 按该分支的 40% 下限执行）；**④ 兜底覆盖**：本文件颜色 §2 与字体 §3 的"参考表"是无分支命中时的兜底，完全命中分支若给出具体色彩 hex / 字号阶梯按命中分支执行；软降级时分支常量值层失效，回退到本文件参考表 + query 改写。**关键厘清**：禁用词扫描范围 = 仅场景标签；禁用词命中只触发分支**软降级**（常量值层失效），**不触发结构层作废**；用户的具体色板/字体/装饰偏好**不视为禁用词**，它们是 override 信号。**命中分支结构层是本项目设计宪法的一部分，应像执行本文件那样完整执行；常量值层在完全命中态下整体执行，在软降级态下由 query / STORY.md 改写填空——"为本项目改造常量值"是允许且必要的，但结构性约束（比例、阶梯、版式分类、装饰白名单结构、自检条件）禁止改造。**

## 设计总则（生成时不要复述，只检查是否落实）
- **一致性优先**：母版骨架、配色、字体、配图风格全程统一，禁止"个别页特殊处理"。
- **密度优先**：极简风的前提是单元素信息密度足够大；空 ≠ 极简。任何一页内容稀薄都是失败。
- **配图骨架化**：配图必须承担叙事功能（占有效面积，与正文耦合），禁止 200×70 的"装饰小贴片"塞在标题栏。
- **大胆对比**：好设计的核心是尺度跳跃和刻意不对称——每页至少一个"视觉锚点"（超大字号/超大图/超大色块），其余元素围绕锚点组织。禁止所有元素趋近中间大小。
- **视觉节奏**：10页以上的PPT必须有2-3页"视觉高潮页"（hero页），其余为"支撑页"（supporting页）。每页视觉重量必须不同，禁止"流水线感"。

## 1. 画布与全局母版
> 画布尺寸默认 1280×720。同类内容页之间的标题位置、页码位置必须保持稳定，禁止逐页随机发挥。封面 / 章节过渡 / 结束页允许有自定义版式。

### 默认母版（A/B/C 三区）
| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | 0–120px | 120px（含上 padding 20） | 主标题 32–40px bold |
| **B · 内容区** | 120–660px | 540px 可用 | 一切正文、图表、配图、卡片；禁止挤占 A/C 区 |
| **C · 页脚条** | 660–720px | 60px（含下 padding 20） | 左侧项目名 / 全局水印（可选） + 右侧页码 `NN / TOTAL`，统一 14px 灰字 |
| 页面 padding | 上下 20px、左右 60–80px | — | A/B/C 在 padding 之内排布 |

项目根目录 `DESIGN.md` 必须把上面三行**写成具体 px 值**，并在每个页面文件中以注释或固定结构复用。
封面 / 章节过渡 / 结束页可省略 C 区或采用自定义版式；其余内容页之间应严格保持母版一致。

## 2. 颜色系统（实例化为具体 hex）
依据PPT的受众和用户的实际需求，构建一组**色彩池**（不超过 4 hex），如下是一些常用的参考色系：

| 主题领域 | 背景 | 主色 | 辅色 | 文本主色 |
| :--- | :--- | :--- | :--- | :--- |
| 科技 / 金融 | `#FFFFFF` 或 `#0F172A` | `#3B82F6` | `#06B6D4` | `#1A1A1A` / `#F7F4EC` |
| 人文 / 哲学 / 文化 | `#F7F4EC`（宣纸米） | `#1A1A1A`（松烟墨） | `#A8351A`（朱砂） | `#3F4A55`（青墨） |
| 教育 / 消费 | `#FAF7F2` | `#F97316` | `#EC4899` | `#1A1A1A` |
| 政务 / 党建 | `#FFFFFF` | `#C8102E` | `#D4AF37` | `#1A1A1A` |

### 2.1 色彩面积分配
在 `DESIGN.md` 的文件中必须声明每页的色彩面积分配：

| 色彩角色 | 面积占比 | 说明 |
| :--- | :--- | :--- |
| **主色** | ≤ 60% | 背景、大色块、标题栏底色 |
| **辅色** | ≤ 30% | 卡片背景、图表第二系列、分隔线 |
| **强调色** | ≤ 10% | 只出现在需要视觉焦点的元素上——巨型数字、CTA按钮、核心数据标注 |
| **中性色** | 剩余 | 文本、页脚、边框 |

**色彩节奏规则**：
- **Hero 页（视觉高潮页）**：强调色占比可提升到 15-20%。
- **Supporting 页（信息承载页）**：强调色≤5%，辅色≤20%。
- **禁止全篇每页色彩比例雷同**。至少2页的色彩比例应与其他页显著不同。

### 2.2 渐变与半透明
**允许且鼓励**：
- `linear-gradient(135deg, #3B82F6 0%, #06B6D4 100%)`：卡片头部、标题栏渐变
- `background: rgba(59,130,246,0.08)`：大面积浅色半透明覆盖
- 背景图上叠加 `rgba(0,0,0,0.4)` 蒙版，让白色文字清晰可读
- 卡片容器使用 `boxShadow: '0 4px 20px rgba(0,0,0,0.08)'` 创造浮起感
- 元素重叠时，底层使用 `opacity: 0.15~0.3`

**项目 `DESIGN.md` 必须声明**：本项目的渐变方案（角度、起止色、使用位置）和半透明策略（哪些元素叠在什么之上、opacity 值）。

### 通用禁忌
- 同一页面出现 ≥ 2 套主色板。
- 高饱和撞色铺满 ≥ 1/3 页面。
- 全篇每页颜色分配比例雷同（差异 < 10%）。

## 3. 字体系统（按层级给出具体 px / pt + 字体个性）
项目 `DESIGN.md` 必须列出每个层级的字号、字重、行高与字距，禁止只写"标题大字、正文小字"。

### 3.1 字号层级表
如下是一些参考推荐，请结合用户的主题和页面内容，分配合适字号：

| 层级 | 字号范围（px）  | 字重 | 行高 | 用途 |
| :--- |:----------| :--- | :--- | :--- |
| 封面主标题 | 60–96     | bold | 1.2 | 仅封面 |
| 章节大字 | 60–80     | bold | 1.1 | 章节过渡、结束页 |
| **巨型数据/锚点** | **72–120** | **bold** | **1.0** | **核心数据、里程碑数字——每页至少1个视觉锚点元素** |
| 页面主标题（标题块） | 32–40     | bold | 1.3 | **每页固定**：三区方案在 A 区，四区方案在 B 区 |
| 副标题 / 卡片小标题 | 24–30     | bold / 600 | 1.4 | 卡片头 |
| 正文 | 22–28     | regular | 1.5 | 段落 |
| 引文 | 20–26     | italic | 1.5 | 「」 |
| 脚注 / 页码 | 14–16     | regular | 1.4 | 页脚条右下 |

### 3.2 字体个性策略
如下是一些参考推荐，请结合用户的主题和页面内容，分配合适字体：

| 气质方向 | 推荐中文字体 | 推荐西文搭配 | 适合主题 |
| :--- | :--- | :--- | :--- |
| 商务现代 | 思源黑体 / 苹方-简 | Helvetica Neue / Inter | 科技、金融、SaaS |
| 人文质感 | 思源宋体 / 方正书宋 | Georgia / Merriweather | 文化、学术、哲学 |
| 活力亲和 | 阿里普惠体 / 站酷快乐体 | Poppins / Nunito | 教育、消费、生活 |
| 政务庄重 | 方正小标宋 / 华文中宋 | Times New Roman | 政务、党建、法律 |
| 科技未来 | 思源黑体 + letterSpacing加大 | Space Grotesk / JetBrains Mono | AI、芯片、航天 |

**关键规则**：
- **标题与正文允许不同字体个性**：标题可用更有表现力的字体（如思源宋体），正文用易读字体（如思源黑体）。
- **巨型数据/锚点数字**：必须用与正文不同的字重或字体。例如正文用 regular 14px，数据用 bold 56px。
- **禁止所有页面只用"系统默认无衬线"**。项目 `DESIGN.md` 必须写出具体字体名。

## 4. 信息密度门禁
如项目走极简 / 留白风格，需在项目 `DESIGN.md` 显式声明"留白型"并覆盖本节默认值。

| 页面类型 | 最少元素数 | 正文字数下限 | 图片/图表数下限 | 主视觉占内容区面积 |
| :--- | :--- | :--- | :--- | :--- |
| 封面 | 主标题 + 副标 + 主视觉 | 20 | 1 | B 区 ≥ 35% |
| 目录 | N 个并列条目 + 引导句 | 80（合计） | 0–1 | — |
| 内容页 · 单主题 | 标题 + 正文 + 主视觉 | **180** | 1 | B 区 ≥ 30% |
| 内容页 · 卡片组 | 标题 + 引导句 + N 卡 | **每卡 ≥ 100**（合计 ≥ 300，3 卡时） | 0–N | — |
| 数据 / 图表页 | 标题 + 主图 + 洞察文字 | 80 | 1 主图 | B 区 ≥ 50% |
| 章节过渡 | 章节大字 + 一句小标 | 30 | 1 | B 区 ≥ 40% |
| 结束页 | 收束金句 + 落款 | 20 | 0–1 | — |

**默认留白上限**：常规内容页留白 ≤ 35%。封面 / 章节过渡 / 结束页及 DESIGN.md 显式声明的"留白型"页不受此限。

### 4.1 容器填充率门禁
- **填充率 ≥ 85%**：卡片/容器内的实际内容（文字 + 引文 + 图标 + 装饰）垂直占用应 ≥ 容器高度的 85%。卡片越高，要求字数越多——高 ≥ 380px 的卡片，正文应 ≥ 100 字；高 ≥ 480px 的卡片，正文应 ≥ 130 字。
- **底栏锚定**：卡片末尾的引文条 / 标签条 / 行动按钮等"尾部元素"，必须用 `marginTop: 'auto'`（或父容器 `justifyContent: 'space-between'`）钉到容器底部；禁止"自然紧跟正文"导致它悬浮在卡片中段。
- **横向兄弟卡对齐**：同一行的多张卡片，其内部"标题块 / 正文块 / 引文条"三段在 y 轴上必须等高对齐。任意两张兄弟卡的尾部元素 y 坐标差 > 16px → 返工。

### 4.2 留白策略
**强制规则**：
- **焦点留白**：每个视觉锚点元素（巨型数字、核心图片、大标题）周围必须留出 ≥ 40px 的呼吸空间。
- **Hero 页允许更多留白**：视觉高潮页的留白可以达 40-50%，但留白必须围绕核心元素（不是均匀散布的空白）。
- **禁止"均匀稀薄"**：一页的留白不是围绕焦点元素、而是每两个元素之间都有差不多大小的空白 → 需要补内容或合并页面。

## 5. 配图系统
项目 `DESIGN.md` 必须把每张配图归类到下列三级之一，并标明出现位置与最小尺寸：

| 等级 | 用途 | 最小尺寸 / 占比 | 接入方式 |
| :--- | :--- | :--- | :--- |
| **L1 · 主视觉** | 承担页面主要叙事 | B 内容区 ≥ 40%；常见 560×420 / 640×480 / 半屏 | 卡片整体背景 / 一栏铺底 / 引文卡叠层 |
| **L2 · 支撑图** | 强化某个段落 | ≥ 280×180 | 段落旁 / 卡片头部 / 与正文并排 |
| **L3 · 母版徽标** | 全篇统一的角标元素 | ≤ 64×64 | 三区方案放在页脚条 C 区左侧或印章位置；四区方案放页眉 A 区。全篇位置必须一致 |

**严禁**：把 200×70 等小尺寸图片塞进标题块右侧当装饰；不同页 L3 位置不固定；全篇 L1 主视觉风格混杂（默认同为摄影 / 同为插画 / 同为 3D，特殊主题需 DESIGN.md 显式声明）。

**配图获取规则**：
1. **无生图工具，不提供 AI 配图**（见 `pptx-api.md` §配图接口）。位图只能来自用户材料，先过上传口换 `url`，把 `url` 直接写进该图位 jsx 的 `src`；逐张核对真实内容、比例、清晰度与风格一致性后再用于对应图位。
2. **材料图原图直传**：一律零重绘，数字 / 文字 / 细节不得走样。
3. **允许 SVG**：流程图、时间轴、矩阵、漏斗、架构图、关系网络、图表底图、巨型数字、趋势箭头、进度环、L3 角标、印章、页脚纹样、背景网格、抽象几何概念页等结构化 / 低语义元素可以用 `<SVG>`。
4. **无可用材料图时的承载**：L1 / L2 图位在材料里找不到可用位图时，用 `<SVG>` / 色块 / 版式留白 / 巨型数字 / 图表承载，并在 `DESIGN.md` 标注为「版式替代」。禁止凭空找图或编造图片来源。

视觉统一规则：
1. 全篇额外绘制的 `<SVG>` 必须统一线宽、圆角、色板与密度，与 `DESIGN.md` 声明的视觉基调一致，禁止混搭。
2. 材料图的风格由素材本身决定，选用时优先挑视觉类型一致的图，避免摄影 / 插画 / 3D 混排。
3. 每个图位定稿前必须核对真实内容、构图、清晰度与风格，确认符合该图位语义后再使用。
