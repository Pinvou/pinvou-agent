# design-principle.redgold.md · 红金政务风

## 1. 风格 DNA

- **红金主视觉**：鲜明朱橙红 + 金色点缀 + 白底内页，热烈但不杂乱。
- **美术层与内页分离**：封面、目录、章节过渡可更强视觉；正文、模型、数据页使用稳定母版。
- **中文优先**：正文、图说、图表标签、章节副标、致谢页均使用中文；仅少量结构性英文允许。
- **密度优先**：空不等于高级；美术层和内容页都要有足够信息与视觉承载。
- **配图贴题**：主视觉必须服务当前页面主题，禁止用通用大景凑数。
- **零旋转纪律**：卡片、文字、飘带、装饰、配图全部 0°，仅 SVG 图表内部几何线例外。
- **禁廉价符号**：禁印章语义、红绸铺满、整屏暗蒙版、局部矩形色块压图。

---

## 2. 母版与版面骨架

画布：1280×720；推荐左右 padding 70。

| 区域 | 范围 | 规则 |
| :-- | :-- | :-- |
| A 留白区 | y 0–48 | 完全留白；禁任何文字、标识、kicker、SECTION、右上小字 |
| B 标题块 | y 48–110 | 中文主标 32–40px，宋体 CN Heavy，黑字；禁中英并排 |
| C 内容区 | y 110–660 | 正文、图表、配图、卡片 |
| D 页脚装饰条 | y 660–700 | 底部红橙 3 段装饰条，高约 9px；可叠页码 `NN / 总页数` |

省略规则：封面、目录、章节过渡、系统标记可省 A/D；前言、正文、模型、图表必须完整遵守。

D 区推荐比例：`#C42819` 53% + `#EE5530` 26% + `#F26B40` 21%；禁完全等宽。

## 4. 英文使用与内容语言

页面可见文字以中文为主。仅以下结构性英文允许：`CONTENTS` / `PART` / `CHAPTER` / `PREFACE` / `SLIDES` / `SWOT` / `SMART` / `PEST` / `KPI`。

禁：A 区任何文字、SECTION 标识、kicker 字样、THANK YOU / THANKS、正文英文短语、图表轴英文、章节副标英译、把中文文案再翻译一遍的装饰英文。

允许：阿拉伯数字、百分号、金额、面积、温度等单位符号，以及非页面可见技术字段中的英文。

## 5. 信息密度与可读性

| 类型 | 下限 |
| :-- | :-- |
| 封面 | 4 字主标 + 副标飘带 + 2 枚药丸 + ≥4 件装饰，整屏视觉 ≥85% |
| 目录 | 主标 + N 编号载体 + N 章节主题，≥80 字，装饰 ≥3 件 |
| 章节过渡 | PART 巨字 + 章节中文 + 中文副标 + 右侧摄影，≥30 字 |
| 前言 | 大卡包长文 ≥220 字 |
| 单主题 | 正文 + 主视觉，≥180 字，图 ≥30% |
| 卡片组 | 每卡 ≥100 字，3 卡 ≥300 字 |
| 思维模型 | 4–7 维度铺齐，≥240 字，SVG ≥50% |
| 数据图表 | 主图 + 洞察 + 关键数字，≥80 字 |

- 内页留白 ≤35%，美术层留白 ≤15%。
- 卡片填充率 ≥75%；卡尾锚底；兄弟卡尾部 y 差 ≤16px。
- 文字与实际背景对比度 ≥4.5:1。
- 禁整屏暗色蒙版；底图 opacity ≥0.85；禁用矩形色块覆盖配图。

## 6. 配图与装饰

### 配图

| 等级 | 用途 | 规则 |
| :-- | :-- | :-- |
| L1 主视觉 | 页面叙事主体 | 美术层 ≥85% 整屏；内页按页型 ≥30–50% |
| L2 支撑图 | 佐证局部内容 | ≥280×180 |
| L3 徽标 / 角标 | 全篇统一 | ≤64×64，内页位置漂移 ≤8px |

配图必须与当前页主题语义一致。章节过渡与内容页禁用通用大景凑数；通用大景最多用于封面 / 致谢等仪式页，且全篇 ≤2 张。每张 L1 必须有 ≥12 字图说说明与内容关系。

### 装饰

允许：红橙底部装饰条、金色水平飘带、红色胶囊药丸、金色粒子/光晕、红色短条、主题摄影、少量地标/纹样剪影。

禁：印章 / 钤印 / 落款章、红底竖排白字章、满屏红绸、满屏金光、整屏暗蒙版、局部矩形蒙版、非 0° 倾斜、玻璃拟态、模糊阴影、复杂渐变卡片。

## 7. 卡片规范

卡体三选一，单页最多混用 2 种：

| 类型 | 规则 | 用途 |
| :-- | :-- | :-- |
| A 标准白卡 | 圆角 12–16px + 1px 浅灰描边 + 白底，无投影 | 通用首选 |
| B 红头白卡 | 顶部红卡头 48–56px + 白底正文区 | 多栏分组 / 强调 |
| C 红色实心卡 | 红底白字，圆角 12–16px | 核心洞察；单页 ≤1–2 张 |

卡内 padding：上/下 20，左/右 24；卡间 gutter ≥24；卡内标题与正文间距 12–16。卡组顶边对齐误差 ≤4px，gutter 误差 ≤4px，卡高差 ≤16px。所有卡片与可见元素严格 0°。

推荐节奏：陈述型白卡 + 少量焦点型红卡，比例约 3:1 或 4:1；避免全页白卡无焦点，也避免全页红卡泛滥。

## 8. 页面类型规则

### ① 封面

- 4 字成语双行错位，单字独立 box，字号 160/190/220 交错。
- 金字必须叠加：金渐变 + 文字投影 + 主标区域光晕聚焦。
- 副标用水平 0° 金色飘带；汇报人 / 时间用红色胶囊药丸。
- 禁单字背后填色矩形、倾斜飘带、整屏暗蒙版、英文副标翻译。

### ② 目录

按章节内容选择：

- 卡组列表型：章节 ≥4 或多议题；用 PART 矩形/胶囊卡，横排或 3×2。
- 故事叙事型：章节 ≤4 且有叙事顺序；左图右内容，阿拉伯圆球编号，单列 4 条。

同一目录页编号载体只能一种。禁金色繁体数字圆球、主编号+副编号双层堆叠、场景与版式不匹配。

### ③ 章节过渡

唯一推荐：白底左右分屏 PART 现代版。

- 左 50%：PART + 巨数 + 红短竖条 + 中文章节名 + 中文副标 + 3 个关键词点。
- 右 50%：主题摄影出血铺满，禁黑白蒙版 / 红色蒙版。
- 底部保留 D 区红橙装饰条。
- 禁满屏红绸、金光束、地标剪影、中部深红承载块、副标英文。

### ④ 前言

- 大 roundRect 白卡包整段长文 ≥220 字。
- 主标“前言 / PREFACE”可保留结构性 PREFACE；正文必须中文无衬线。

### ⑤ 正文

- 三栏并列卡：每卡 ≥100 字，红头白卡或标准白卡。
- 四/六栏卡：用于多要点，卡内必须有标签、主体、说明三层。
- 时间/阶段轴：线 + 圆节点，中文标签。
- 大图配文：L1 ≥40% C 区，图说说明关联。
- 数据强调：KPI 数字 72–120px，图表标签中文。
- 对比 / 关键词矩阵 / 综合复杂页必须遵守卡片规范与零旋转。

### ⑥ 思维模型

- 超大模型缩写 + 4–7 张说明卡；模型缩写可用 SWOT/SMART/PEST/KPI。
- 卡内维度释义必须中文；多张模型页视觉同款。

### ⑦ 数据图表

- 主图 + 右侧洞察，或 4 KPI + 主图组合。
- 图例、坐标轴、单位说明必须中文；涨跌可用红 / 绿。
- 禁 3D、彩虹色、英文 Revenue/YoY/Growth Rate 等标签。

### ⑧ 系统标记

- 单行灰字，交付前删除。

## 9. 最终硬闸门

出现以下任一情况必须返工：

1. A 区出现任何文字 / 标识 / kicker / SECTION / 右上小字。
2. D 区缺红橙三段装饰条，或 3 段完全等宽。
3. B 区主标非中文、非宋体 Heavy、字号 <32px，或中英并排。
4. 正文使用衬线宋体，或主标使用黑体。
5. 页面出现非结构性英文，尤其正文、图表、章节副标、致谢页英文。
6. 色板越界：米白底、冷暗红、纯橙、屎黄、蓝紫品红等禁色。
7. 金色占比超限，或美术层 / 内页红白金比例失衡。
8. 文字对比度 <4.5:1，或靠整屏暗蒙版保对比度。
9. 任意可见元素非 0° 旋转（SVG 图表内部线条例外）。
10. 出现印章语义元素、落款章、红底竖排白字章。
11. L1 配图与页面主题不符，或通用大景在章节/内容页凑数。
12. L1/L2 被局部矩形色块覆盖，或底图 opacity <0.85。
13. 封面缺金渐变、投影、光晕任一项，或字下出现填色矩形。
14. 目录编号载体不单一，或场景与版式不匹配。
15. 章节过渡未走白底左右分屏 PART 现代版。
16. 卡片 padding / 对齐 / 填充率 / 零旋转任一失守。
17. 思维模型多页不同款，字体层级或卡片框不统一。
18. 占位文未清零。
