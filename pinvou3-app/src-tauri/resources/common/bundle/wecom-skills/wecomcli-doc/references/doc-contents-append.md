# 追加内容到在线文档 — `wecom-cli doc contents append`

在**doc文档**的末尾追加新的文本内容，不影响已有内容。

## 命令

```bash
wecom-cli doc contents append --json '<JSON 参数>'
```

## 参数

| 字段 | 类型 | 必填 | 默认值 | 语义                        |
|---|---|---|---|---------------------------|
| `docid` | string | 是 | — | doc文档 ID                  |
| `content` | string | 是 | — | 要追加的文本内容；支持格式：`text`（纯文本） |

## 返回

追加成功返回空对象。

## 超时与结果不明

追加是**非幂等**写操作：命令遇网络超时 / 返回丢失时内容可能已追加成功，也可能没有。接口不返回可关联本次调用的凭据（无调用 ID / 幂等键），因此**禁止自动重试，也禁止以读回结果自动判定成败**：

- 文末已出现相同文本**不能证明**本次追加已生效——用户此前可能合法追加过同样内容，读回会把它误认成本次的；
- 文末尚未出现**也不能证明**原请求不会延迟生效——服务端可能仍在处理，此时补写会重复追加。

正确做法：停止自动操作，向用户如实报告「结果未知」，并说明可用 SKILL.md「读取doc文档内容」（`contents get`）人工核对文末；仅在用户明确确认此前未追加成功后，才补写一次（计入 SKILL.md「业务失败处理」的 2 次上限）。
