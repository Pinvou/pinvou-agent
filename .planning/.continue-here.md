# Pinvou CLI TUI 跨机器续作检查点

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---|---|---|---|
| 未确认视觉合同就继续微调 | 实际 TUI 已明显偏离此前 HTML 视觉方向，单纯增加颜色或边框无法达到 Claude Code / Codex 级体验 | blocking | 恢复后先完成浏览器视觉稿与实际 TUI 的并排评审，冻结状态与组件合同后再写实现计划 |
| 把运行时初始化事件误判为协议错误 | 真实 Codex 会在 `turn.started` 前发送无 `turn_id` 的 `vendor`、`log.record`；旧逻辑因此提前断流 | advisory | 保留 `stream_accepts_codex_initialization_events_before_turn_started` 回归测试，新增 adapter 时按事件语义而不是到达位置分类 |
| 回到显式 `pinvou tui` 或附带控制台窗口 | 已与用户确认的默认启动方式冲突，且 Windows 子进程窗口破坏产品体验 | advisory | `pinvou` 默认进入 TUI；Windows Controller/Node 使用隐藏窗口创建标志 |
