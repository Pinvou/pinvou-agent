# 契约：语音输入 UI 行为

## 入口

聊天输入区提供语音输入入口。用户点击后，系统进入语音输入会话。

## 状态契约

| 状态 | 用户可见表现 | 允许操作 |
|---|---|---|
| idle | 语音输入未启动 | 启动 |
| requesting_permission | 正在请求或检查麦克风权限 | 取消 |
| recording | 正在录音，有明显录音状态 | 停止、取消 |
| transcribing | 正在识别语音文本 | 取消或等待 |
| completed | 文本进入启动时的输入上下文 | 编辑、发送 |
| cancelled | 保留启动前文本 | 重新启动 |
| failed | 展示失败原因和建议 | 重试、关闭提示 |

## 回填契约

- 成功识别文本追加或写入启动语音输入时所在的输入框。
- 如果用户在识别期间切换会话，系统不得把文本写入错误会话。
- 如果已有草稿文本，语音文本不得覆盖草稿，除非用户明确选择替换。
- 空识别结果必须提示“未识别到语音内容”或等价说明。

## 错误提示契约

| 错误类别 | 用户提示要求 |
|---|---|
| 权限拒绝 | 告知需要开启麦克风权限 |
| 设备不可用 | 告知未检测到可用麦克风或设备被占用 |
| 录音失败 | 告知录音启动失败并允许重试 |
| 识别失败 | 告知语音识别失败并允许重试 |
| 超时 | 告知本次语音输入超时并允许重试 |

## 非目标

- 不要求新增音频文件转写 UI。
- 不要求新增说话人分离、长音频上传或语音历史管理。
