# 契约：语音输入诊断

## 诊断目标

Windows 语音输入失败时，开发者能够判断失败发生在权限、设备、录音、识别或回填阶段。

## 事件字段

| 字段 | 要求 |
|---|---|
| stage | `permission`、`device`、`recording`、`transcribing`、`writeback` 之一 |
| level | `info`、`warn`、`error` 之一 |
| message | 简短、可搜索、无敏感信息 |
| user_message | 需要展示给用户时提供中文提示 |

## 记录边界

- 不记录原始音频。
- 不记录完整用户输入文本。
- 不记录 API key、token、cookie 或完整本地敏感路径。
- 可以记录平台、权限状态、错误类别、是否有设备、是否超时。

## 验收

- 至少覆盖权限拒绝、无设备、录音失败、识别失败、回填上下文不匹配五类事件。
- 用户可见错误与诊断事件能够对应到同一错误类别。
