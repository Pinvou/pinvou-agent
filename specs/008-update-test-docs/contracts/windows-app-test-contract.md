# UI 测试合约：Windows 全功能测试参考

本文档定义测试人员可以直接观察和验证的 UI 合约。它描述入口、操作、期望状态和失败反馈，不要求了解内部实现。

## 1. 启动与导航

**入口**：Windows 桌面快捷方式、开始菜单或安装目录。

**必须可见**：

- 主窗口可打开且可交互。
- 主要页面入口：聊天、监控、设置、工作流、专家卡、产物、工具市场。
- 当前页面有明确选中或上下文提示。

**失败反馈**：

- 后端不可用不应导致白屏。
- 页面数据加载失败时应显示空状态或错误状态。

## 2. 聊天与会话

**入口**：聊天页和会话列表。

**必须可操作**：

- 新建会话、加载会话、重命名会话、删除会话。
- 发送消息、取消生成、编辑上一轮。
- 多会话切换时保留各自生成状态和历史内容。

**必须可见**：

- 用户消息、助手回复、流式更新。
- 会话忙碌、后台生成或失败状态。
- 空会话和历史会话的差异。

## 3. 设置与模型状态

**入口**：设置页。

**必须可操作**：

- 修改并保存模型配置。
- 切换语言和主题。
- 探测本地模型服务或查看后端状态。
- 检查系统权限、依赖和版本更新。

**必须可见**：

- 保存成功或失败反馈。
- 服务可用、不可用、检测中或错误状态。
- 配置重启要求或重启结果。

## 4. 附件与产物

**入口**：聊天输入区、附件区、产物面板。

**必须可操作**：

- 选择文件、拖拽文件、粘贴图片。
- 删除未发送附件。
- 打开产物预览、系统打开文件、定位文件夹、打开独立产物窗口。

**必须可见**：

- 附件名称、类型和处理状态。
- 产物名称、类型、路径或元信息。
- 依赖缺失、解析失败或文件不存在错误。

## 5. Plan、工具和用户输入卡片

**入口**：聊天页模式切换、消息流中的卡片。

**必须可操作**：

- 进入 Plan 模式。
- 接受或丢弃计划。
- 提交或取消用户输入请求。
- 在允许时退出 Plan 或切换执行模式。

**必须可见**：

- 计划卡片状态。
- 工具调用执行中、完成、失败或阻塞状态。
- 上下文压缩或 token 状态提示。

## 6. 专家卡与技能

**入口**：专家卡池、技能列表或会话绑定区域。

**必须可操作**：

- 搜索、筛选、查看专家卡。
- 装备和卸下专家卡。
- 创建、编辑和删除自定义专家卡。
- 查看技能正文或示例，启动或解除技能绑定。

**必须可见**：

- 当前会话已装备专家卡。
- 卡片保存、删除或绑定失败信息。
- 技能绑定状态。

## 7. 工作流

**入口**：工作流页面。

**必须可操作**：

- 查看模板。
- 创建工作流任务。
- 添加材料。
- 查看角色详情。
- 批准或拒绝门禁。
- 重试或取消角色。

**必须可见**：

- 运行卡片和角色状态。
- 输出、日志、提示词和文件预览。
- 等待用户输入、失败、完成或取消状态。

## 8. 监控与工具市场

**入口**：监控页、工具市场页。

**必须可操作**：

- 刷新或查看监控状态。
- 安装和卸载工具。

**必须可见**：

- 后端、模型、GPU、内存或不可用状态。
- 工具已安装、未安装、安装中、卸载中和失败状态。
- 网络失败或本地状态不一致提示。

## 9. Windows 更新与依赖

**入口**：设置页的版本与更新、依赖检查区域。

**必须可操作**：

- 检查更新。
- 下载并安装更新。
- 下载中取消。
- 查看依赖检查结果。
- 在支持时触发依赖安装。

**必须可见**：

- 当前版本。
- 检查中、已是最新、发现新版本、检查失败。
- 下载进度、取消中、安装中、安装器已启动。
- 更新失败原因。
- 依赖可用、缺失、安装中、失败或不支持。

**Windows 特定要求**：

- MSI 安装应请求管理员权限。
- MSI 启动成功后当前应用应退出。
- 安装完成后新版本应用应启动。
- 升级结果反馈不得阻塞主界面。

## 10. 多语言与错误展示

**范围**：中文、英文、日文界面。

**必须验证**：

- 主要页面入口无空白文案。
- 按钮文案不截断到不可理解。
- 错误状态和空状态语义一致。
- 语言切换后不会残留大量上一语言文案。

## 11. 合约覆盖矩阵

| 合约章节 | 对应用户故事 | 必须覆盖的失败状态 |
|---|---|---|
| 启动与导航 | US1 | 白屏、页面数据加载失败、后端不可用 |
| 聊天与会话 | US2 | 生成失败、取消生成、会话切换状态丢失 |
| 设置与模型状态 | US3 | 配置保存失败、模型不可达、依赖缺失 |
| 附件与产物 | US4 | 文件解析失败、产物不存在、系统打开失败 |
| Plan、工具和用户输入卡片 | US5 | 工具失败、工具阻塞、用户取消输入 |
| 专家卡与技能 | US6 | 保存失败、删除失败、绑定失败 |
| 工作流 | US7 | 角色失败、门禁拒绝、取消运行 |
| 监控与工具市场 | US8 | 监控数据缺失、市场网络失败、安装卸载失败 |
| Windows 更新与依赖 | US9 | 检查失败、下载失败、UAC 拒绝、MSI 启动失败、反馈失败 |
| 多语言与错误展示 | US1-US9 | 文案为空、截断、乱码或语言残留 |
