# 数据模型：Windows 全功能测试参考清单

本文档描述测试人员在 Windows 功能验证中需要识别的关键业务对象。它不是数据库设计，也不要求测试人员了解内部实现。

## 会话

**含义**：一次聊天上下文和工作上下文。

**关键属性**：

- 标题和会话标识
- 消息列表
- 当前生成状态
- 忙碌或后台生成状态
- 附件、产物、专家卡和技能绑定
- 最近使用时间和持久化状态

**测试关注点**：创建、切换、重命名、删除、重启恢复、生成中切换、多会话状态隔离。

## 消息/聊天项

**含义**：会话中的可见内容单元。

**关键类型**：

- 用户消息
- 助手流式回复
- 工具调用卡片
- Plan 卡片
- 用户输入请求卡片
- 错误、阻塞和上下文压缩提示

**测试关注点**：流式追加、取消、失败展示、卡片按钮状态、跨会话不串扰。

## 设置

**含义**：影响应用连接模型、显示语言、主题、系统能力和更新行为的配置。

**关键属性**：

- 模型供应商、服务地址、模型名和 API Key
- 搜索与推理相关配置
- 语言、主题和界面显示偏好
- 后端状态、本地模型探测和重启入口
- 系统权限、依赖检查、版本与更新状态

**测试关注点**：保存、重启后生效、错误配置反馈、多语言文案、状态刷新。

## 附件

**含义**：用户加入会话的文件或图片。

**关键属性**：

- 来源：选择、拖拽、粘贴
- 文件名、路径、大小和类型
- 解析或保存状态
- 依赖缺失或失败信息

**测试关注点**：中文路径、空格路径、格式不支持、文件占用、依赖缺失、随消息发送。

## 产物

**含义**：会话或工具生成的可查看结果。

**关键属性**：

- 文件路径和展示名称
- 类型：文本、图片、可视化文件或其他交付物
- 预览状态和元信息
- 系统打开、定位文件夹、独立窗口打开入口

**测试关注点**：预览、打开、定位、文件丢失、路径权限、中文路径。

## 专家卡

**含义**：可装备到会话的角色或专家能力。

**关键属性**：

- 内置或用户自定义
- 名称、分类、部门、描述和正文
- 当前会话装备状态
- 创建、编辑和删除权限

**测试关注点**：浏览筛选、装备卸下、CRUD、会话绑定持久化、删除已绑定卡片的表现。

## 技能绑定

**含义**：会话与某个技能能力之间的绑定关系。

**关键属性**：

- 技能名称和描述
- 技能正文和示例
- 当前会话绑定或未绑定状态

**测试关注点**：查看详情、启动技能会话、解除绑定、重启后状态。

## 工作流运行

**含义**：由模板启动的多角色协作任务。

**关键属性**：

- 模板、目标、材料和运行标识
- 角色状态：等待、运行、完成、失败、取消
- 输出、日志、提示词和文件预览
- 门禁审批、拒绝、重试和取消状态

**测试关注点**：启动、恢复、材料追加、门禁处理、角色失败、重试、取消。

## 工具市场项

**含义**：可安装、卸载或展示状态的扩展工具。

**关键属性**：

- 名称、描述和来源
- 已安装、未安装、安装中、卸载中、失败状态
- 操作按钮和错误信息

**测试关注点**：列表加载、安装、卸载、网络失败、本地状态不一致。

## 监控快照

**含义**：应用用于展示运行环境和模型状态的一组只读数据。

**关键属性**：

- 后端连接状态
- 模型可用性
- GPU、内存或资源状态
- 最近刷新时间或错误状态

**测试关注点**：数据可用、数据缺失、无 GPU、后端断开、刷新错误。

## 更新任务

**含义**：Windows 下从检查更新到反馈升级结果的状态集合。

**关键属性**：

- 当前版本和目标版本
- 检查状态、下载状态、进度和取消状态
- MSI 启动、管理员权限、安装结果和反馈状态

**测试关注点**：无更新、有更新、下载取消、校验失败、MSI 提权、安装后启动、反馈重试。

## 依赖状态

**含义**：文件解析、预览或系统集成所需外部能力的可用性。

**关键属性**：

- 依赖名称
- 已安装、缺失、安装中、失败或不支持
- 诊断信息和操作入口

**测试关注点**：检查准确性、缺失提示、安装入口状态、失败可诊断。
