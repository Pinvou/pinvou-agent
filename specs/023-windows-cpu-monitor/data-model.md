# 数据模型：Windows 系统监控改为 CPU 卡片

## CPU 监控快照

表示一次系统监控刷新中的 CPU 数据集合。

### 字段

- `name`：字符串；CPU 名称，获取失败时可为空或使用不可用提示。
- `total_usage_pct`：整数或浮点数；总体 CPU 使用率，范围 0 到 100。
- `process_usage_pct`：整数或浮点数；pinvou3 当前进程 CPU 使用率，范围 0 到 100。
- `logical_processors`：正整数；逻辑处理器数量。
- `available`：布尔含义；由字段是否可用推导，前端可用来决定占位状态。

### 验证规则

- `total_usage_pct` 小于 0 时视为不可用，大于 100 时应钳制或拒绝展示为正常值。
- `process_usage_pct` 小于 0 时视为不可用，大于 100 时应钳制或拒绝展示为正常值。
- `logical_processors` 为 0 或缺失时显示占位值，不隐藏整张 CPU 卡片。
- 任一字段不可用不得导致整个系统监控快照失败。

## 系统监控快照

现有系统监控页每次轮询得到的完整快照。

### 新增/调整字段

- `cpu`：可选 CPU 监控快照；Windows 上应尽量提供，非 Windows 可为空。
- `gpu`：现有 GPU 监控快照；非 Windows 保持当前展示路径，Windows 可继续采样但页面不再以 GPU 卡片呈现。
- `generated_at_ms`：现有采样时间；CPU 卡片沿用该时间展示数据新鲜度。

### 关系

- 系统监控页在 Windows 上优先使用 `cpu` 渲染资源卡片。
- 系统监控页在非 Windows 上继续使用 `gpu` 渲染资源卡片。
- RAM、模型服务、应用自测指标与 CPU 快照相互独立，CPU 失败不影响其它区域。

## 系统监控卡片

用户可见的资源展示区域。

### Windows 展示项

- 标题：处理器（CPU）
- 主标题：CPU 名称或不可用状态
- 进度条：总体 CPU 使用率
- 辅助指标：应用进程 CPU 使用率、逻辑处理器数量
- 时间：沿用系统监控页刷新时间

### 非 Windows 展示项

- 保持现有 GPU 卡片展示项和行为。
