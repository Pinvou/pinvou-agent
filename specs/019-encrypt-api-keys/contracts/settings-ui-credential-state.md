# 契约：设置页凭据状态 UI

## 适用范围

本契约约束设置页中大模型配置的 API Key 展示、编辑、保存、替换和删除行为。

## 展示状态

| 状态 | UI 文案要求 | 输入框行为 |
|---|---|---|
| 未配置 | 显示“未配置”或等价提示 | 空输入框，可输入新 Key |
| 已配置 | 显示“已配置”或掩码，不显示完整 Key | 输入框为空或显示占位，不自动填入真实 Key |
| 环境变量覆盖 | 显示“由环境变量覆盖” | 用户可编辑 settings Key，但需提示当前运行优先使用环境变量 |
| 需重新配置 | 显示“凭据不可用，请重新配置” | 允许输入新 Key |
| 保存失败 | 显示安全错误提示 | 保留用户当前输入，错误不包含完整 Key |

## 编辑规则

- 用户打开已有模型配置时，不得默认显示完整 Key。
- 用户不修改 Key 并保存其它字段时，不得删除原有受保护 Key。
- 用户输入新 Key 并保存时，后端替换受保护 Key。
- 用户点击删除/清除 Key 时，后端删除受保护 Key，并将状态改为未配置。
- 输入框中的明文 Key 只在当前编辑会话中存在，保存或取消后应从前端状态中清除。

## 保存 payload 约定

前端向后端保存模型配置时必须区分三种意图：

- `keep_existing`：不改动已保存 Key。
- `replace`：用本次输入的新 Key 替换旧 Key。
- `delete`：删除已保存 Key。

如果继续沿用现有 `api_key` 字段，必须额外提供等价的意图字段，避免“空字符串”同时表示“不改变”和“删除”。

## 连接测试

- 用户输入新 Key 后，可以用该 Key 发起连接测试。
- 对已配置但未显示完整 Key 的模型，连接测试应由后端使用受保护 Key 完成，或提示用户输入新 Key 后测试。
- 连接测试结果不得回显完整 Key。

## 可访问性与反馈

- Key 状态变化必须有清晰文本反馈，不能只依赖颜色。
- 保存失败、凭据不可用、环境变量覆盖等状态必须能被屏幕阅读器读取。
- 删除 Key 应有明确确认或可理解的危险操作提示。
