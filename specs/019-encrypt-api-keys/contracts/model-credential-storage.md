# 契约：模型凭据存储与迁移

## 适用范围

本契约约束 Tauri 后端中大模型 API Key 的保存、读取、迁移、删除和错误处理。它不覆盖搜索 API Key、反馈服务凭据、MCP marketplace 配置字段或其它第三方凭据。

## 存储契约

### 保存新 Key

**输入**：
- 模型配置 id
- 用户输入的新 API Key
- 非敏感模型配置字段

**行为**：
- 后端必须将新 Key 写入当前系统用户的受保护凭据存储。
- 后端必须在 `settings.json` 中保存非敏感模型配置和凭据引用/状态。
- 后端不得在 `settings.json` 中保存完整明文 Key。

**失败**：
- 如果系统凭据存储写入失败，保存操作必须失败并返回可理解错误。
- 错误信息不得包含用户输入的完整 Key。
- 失败时不得把 Key 退回写入普通配置文件。

### 读取 Key

**输入**：
- active model id 或 session model id
- 当前环境变量集合

**优先级**：
1. `DEEPSEEK_API_KEY`
2. 模型绑定的受保护凭据
3. 本地 vLLM 默认占位 Key
4. missing/unavailable 状态

**输出**：
- 后端内部可获得真实 Key 用于模型请求。
- 前端默认只获得 `credential_state`、`has_secret`、`env_overrides` 等脱敏状态。

### 删除 Key

**输入**：
- 模型配置 id

**行为**：
- 删除受保护凭据存储中的对应条目。
- 更新 settings 中的凭据引用/状态为 `missing`。
- 后续模型请求不得继续使用旧 Key。

### 替换 Key

**输入**：
- 模型配置 id
- 新 Key

**行为**：
- 新 Key 成功写入后覆盖旧凭据。
- settings 仍只保存同一模型的凭据引用/状态。
- 后续请求使用新 Key。

## 迁移契约

### 旧配置识别

旧配置包括：
- `advanced.saved_models[*].api_key` 中存在非空字符串。
- `advanced.custom_api_key` 中存在非空字符串，且该值尚未迁移到默认模型。

### 迁移行为

- 启动或读取设置时检测旧明文 Key。
- 将旧 Key 写入受保护凭据存储。
- 迁移成功后清空普通配置中的完整明文 Key。
- 迁移过程必须幂等：重复启动不得重复创建不一致凭据，也不得重新写入明文。

### 迁移失败

- 不得在日志或错误中输出完整 Key。
- 不得删除唯一可恢复的旧配置，除非已成功写入受保护凭据。
- 设置页必须能提示用户“需重新配置”或“凭据存储不可用”。

## 脱敏契约

- 所有日志、错误、诊断导出、前端状态快照、设置页展示均不得包含完整 API Key。
- 如需展示已配置状态，只能展示固定文案、布尔状态或掩码。
- 连接测试可以临时接收用户输入的新 Key，但不得持久化或回传完整 Key。
