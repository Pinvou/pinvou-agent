# 功能规格：加密存储 MCP API 密钥

**功能分支**：`020-encrypt-mcp-secrets`

**创建日期**：2026-06-26

**状态**：Draft

**输入**：用户描述：“修复同花顺/企查查/高德天气等MCP API 密钥明文存储的问题”

## 用户场景与测试 *(必填)*

### 用户故事 1 - 内置 MCP 密钥不再明文落盘 (Priority: P1)

作为 Pinvou 用户，我希望同花顺、企查查、高德天气等内置 MCP 工具的 API 密钥不会以明文出现在本机配置文件中，以降低日志、备份、截图或误读文件导致的泄露风险。

**为什么是此优先级**：当前内置 MCP 工具的密钥会出现在用户目录下的可读配置文件中，这是直接的安全风险。

**独立测试**：安装或启动应用后，检查用户目录下的 MCP 工具清单和 MCP 运行配置文件，确认同花顺、企查查、高德天气的真实 API 密钥均不以明文形式出现。

**验收场景**：
1. **Given** 用户首次启动包含内置 MCP 工具的应用，**When** 应用完成初始化，**Then** 用户目录下的 MCP 工具清单不包含真实 API 密钥。
2. **Given** 用户安装同花顺、企查查或高德天气 MCP 工具，**When** 应用生成 MCP 运行配置，**Then** 运行配置不包含真实 API 密钥明文。

---

### 用户故事 2 - 已有明文配置自动迁移 (Priority: P2)

作为已经安装过旧版本的用户，我希望应用升级后自动处理本机已有的明文 MCP API 密钥，避免升级后仍残留旧风险。

**为什么是此优先级**：仅修复新安装不能保护已有用户，旧配置中的明文密钥仍可能被读取或备份。

**独立测试**：准备包含旧版明文 MCP 密钥的用户目录，启动新版应用后，确认 MCP 工具仍可使用，并且原配置文件中的真实密钥被移除。

**验收场景**：
1. **Given** 用户目录中已有包含明文密钥的 MCP 工具清单，**When** 用户启动新版应用，**Then** 应用迁移密钥并清理清单中的明文值。
2. **Given** 用户目录中已有包含明文密钥的 MCP 运行配置，**When** 用户启动或重新安装对应 MCP 工具，**Then** 应用迁移密钥并清理运行配置中的明文值。

---

### 用户故事 3 - 密钥缺失时给出可恢复反馈 (Priority: P3)

作为用户，我希望当某个 MCP 工具所需密钥缺失或不可用时，应用能明确告诉我哪个工具需要重新配置，而不是静默失败或暴露密钥内容。

**为什么是此优先级**：安全修复不能让 MCP 工具变得难以诊断，用户需要知道如何恢复服务。

**独立测试**：删除某个 MCP 工具的安全凭据后尝试安装或使用该工具，确认应用给出明确且不包含密钥内容的错误信息。

**验收场景**：
1. **Given** 同花顺 MCP 工具的密钥缺失，**When** 用户安装或启用该工具，**Then** 应用显示需要重新配置同花顺密钥的明确提示。
2. **Given** 凭据迁移失败，**When** 应用报告错误，**Then** 错误信息不包含真实 API 密钥。

### 边界情况

- 用户目录中同时存在新格式凭据引用和旧格式明文密钥时，系统应优先保护并清理明文，不应覆盖已有有效凭据。
- 某个内置 MCP 工具没有密钥或不需要密钥时，不应被错误标记为配置异常。
- 多个远程 MCP 服务共享同一个供应商密钥时，密钥应只保存一份逻辑凭据，所有相关服务均可正常使用。
- 迁移过程中发生权限、凭据服务不可用或配置文件损坏时，系统应保留用户可恢复路径，不应把明文密钥写入新的配置文件。
- 诊断日志、错误弹窗、工具市场展示和调试输出均不得显示真实密钥。

## 需求 *(必填)*

### 功能需求

- **FR-001**: 系统 MUST 确保内置 MCP 工具资源中不包含同花顺、企查查、高德天气等供应商的真实 API 密钥明文。
- **FR-002**: 系统 MUST 在用户目录生成或刷新 MCP 工具清单时，不写入真实 API 密钥明文。
- **FR-003**: 系统 MUST 在 MCP 工具安装或启用后生成的运行配置中，不写入真实 API 密钥明文。
- **FR-004**: 系统 MUST 将 MCP API 密钥保存到受保护的凭据位置，并在需要运行 MCP 工具时安全取得密钥。
- **FR-005**: 系统 MUST 识别旧版用户目录中的 MCP 明文密钥，并将其迁移到受保护的凭据位置。
- **FR-006**: 系统 MUST 在迁移成功后清理旧版工具清单和运行配置中的真实 API 密钥明文。
- **FR-007**: 系统 MUST 支持同花顺、企查查、高德天气三类现有内置 MCP 密钥，并允许后续内置 MCP 工具使用同一密钥保护机制。
- **FR-008**: 系统 MUST 在密钥缺失、迁移失败或凭据不可用时，向用户提供明确、可操作、且不包含密钥内容的反馈。
- **FR-009**: 系统 MUST 避免在日志、错误消息、前端状态、工具列表或诊断信息中输出真实 API 密钥。
- **FR-010**: 系统 MUST 保持已安装 MCP 工具的用户体验连续性；完成安全迁移后，用户无需重新安装工具即可继续使用已配置的 MCP 功能。

### 关键实体 *(涉及数据或文档结构时填写)*

- **MCP 工具清单**：描述内置 MCP 工具的名称、分类、命令、服务、所需密钥声明和展示信息；不得承载真实密钥。
- **MCP 运行配置**：应用交给 MCP 运行时使用的工具启用配置；不得持久化真实密钥。
- **MCP 密钥凭据**：某个供应商或工具所需的敏感访问令牌，包含供应商、用途、状态和是否可用等非敏感元信息。
- **迁移记录**：用于判断旧版明文密钥是否已处理的状态信息，帮助避免重复迁移或覆盖有效凭据。

## 成功标准 *(必填)*

### 可度量结果

- **SC-001**: 首次启动新版应用后，用户目录下 MCP 工具清单和运行配置中，目标供应商真实 API 密钥明文出现次数为 0。
- **SC-002**: 从旧版明文配置升级的用户，至少 95% 的正常配置场景可在首次启动后自动完成迁移并继续使用原 MCP 工具。
- **SC-003**: 密钥缺失或迁移失败时，用户能在 1 次错误提示内明确知道哪个 MCP 工具需要重新配置。
- **SC-004**: 安全修复后，同花顺、企查查、高德天气 MCP 工具的安装、启用和调用流程不增加额外手工步骤。
- **SC-005**: 错误消息、日志和用户可见文本中，真实 API 密钥泄露数量为 0。

## 假设

- 本功能聚焦 Pinvou 内置或工具市场管理的 MCP 工具密钥；用户手工创建的第三方 MCP 配置不强制迁移，但不得被新流程继续写入明文密钥。
- 同花顺、企查查、高德天气是本次必须覆盖的目标供应商；后续供应商应复用同一安全机制。
- 用户允许应用使用操作系统或应用环境提供的受保护凭据能力来保存敏感密钥。
- 本功能不改变 MCP 工具本身的业务能力、路由规则或供应商 API 权限范围。
