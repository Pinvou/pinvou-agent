# 契约：依赖体检压缩包项

## 目标

Windows 内置压缩包解析能力后，依赖体检不再误导用户安装 Linux/系统级压缩包依赖；Linux 仍保持现有提示。

## Windows

### 内置资源可用

- 压缩包依赖项不显示为缺失。
- 不展示 `p7zip-full`、`7z` 手动安装提示。
- 上传压缩包时使用内置资源。

### 内置资源缺失或损坏

- 上传压缩包返回修复/重新安装 pinvou 的提示。
- 依赖体检可以隐藏该项，也可以展示为应用安装损坏；不得展示 Linux 包名。

## Linux

- 压缩包依赖项继续检查系统级 `7z`。
- 缺失时继续提示安装 `p7zip-full`。
- 一键安装白名单保持包含 `p7zip-full`。

## Unsupported/Other

- 不宣称 Windows 内置能力可用于其他平台。
- 如果平台不支持压缩包解析，应返回清晰的不可用提示。

## 验证

- Windows 无系统级 7z：依赖体检不提示 `p7zip-full`。
- Linux 无系统级 7z：依赖体检提示 `p7zip-full`。
- Windows 安装目录删除 `7zip/` 后上传压缩包：错误指向内置组件缺失。
