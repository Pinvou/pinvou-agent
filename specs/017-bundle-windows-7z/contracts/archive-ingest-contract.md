# 契约：压缩包导入

## 目标

保证 Windows 内置 7z 后，用户上传 zip、rar、7z 的可见行为与现有系统级 7z 路径一致。

## 输入

- 用户通过附件上传入口选择一个压缩包文件。
- 支持范围保持为：
  - `.zip`
  - `.rar`
  - `.7z`

## 成功输出

当压缩包可解析且未触发安全限制时，返回的 ingest 结果必须满足：

- `kind` 为 `archive`
- `basename` 为原始压缩包文件名
- `path` 为原始压缩包路径
- `markdown` 包含压缩包内文件数量和每个可识别文件的解析段落
- `warning` 为空

## 失败输出

以下场景必须返回可理解 warning：

- 内置压缩包工具缺失或不可执行
- 压缩包损坏或格式不支持
- 压缩包为空或无可识别内容
- 压缩包需要密码
- 条目数或解压后总大小超过现有安全限制

Windows 下工具缺失提示必须指向“内置压缩包解析组件缺失或不可用，请修复或重新安装 pinvou”，不得提示 `sudo apt install p7zip-full`。

## 不变行为

- 解压前仍进行列表预检。
- 嵌套压缩包仍不展开，只在汇总中提示未展开。
- 内部文件继续调用现有 `ingest()` 流程。
- 临时目录解析结束后应清理。

## 验收样本

- zip：包含中文 txt 的普通压缩包
- 7z：包含中文 txt 的普通压缩包
- rar：包含中文 txt 的普通压缩包，必须解析成功
- 损坏包：任意伪造或截断压缩包
- 空包：无文件条目的压缩包
