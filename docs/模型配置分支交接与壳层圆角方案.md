## 当前用户反馈的 UI 问题

用户截图标出的不是单纯 titlebar 重复问题，而是全局 shell 的壳层结构问题：

- 窗口顶部 titlebar 和侧边栏背景需要统一。
- 主内容区应该是独立 surface，覆盖在 shell 背景上。
- 主内容区左上角必须是弧形圆角，而不是直角白块。
- 浅色模式下，红框位置现在露出了直角，需要改成 WorkBuddy 类似的圆角过渡。
- 深色模式也要同样处理，只是颜色换成深色主题。

这应该做在全局 app shell，不应该只改 `MonitorView` 或某个页面。

## 设计目标

### 浅色模式

1. 外层 shell、窗口顶栏、侧边栏使用同一浅色背景。
   - 当前候选色：`#F0F4F9`，与当前浅色侧边栏一致。
2. 主内容区使用白色或近白 surface。
   - 当前候选色：`#FFFFFF`。
3. 主内容区左上角使用明显圆角。
   - 推荐 `border-top-left-radius: 32px`。
4. 圆角外侧露出浅色 shell 背景，形成 WorkBuddy 那种壳层包裹关系。
5. 主内容顶部不能出现红框里的白色直角缺口。

### 深色模式

1. 外层 shell、窗口顶栏、侧边栏使用同一深色背景。
   - 当前候选色：`#131314` 或侧边栏展开态 `#1E1F20`。
   - 更推荐先统一为 `#131314` 作为外壳底色，避免 titlebar 和收起侧边栏断层。
2. 主内容区使用独立深色 surface。
   - 当前候选色：`#0F1012` 或 `#111315`。
3. 主内容区左上角同样使用 `32px` 圆角。
4. 圆角外侧露出深色 shell 背景。
5. 保留主内容和侧边栏之间的层次，但不要形成旧式整条黑色横幅。

## 建议实现方案

主要文件：`pinvou3-app/src/app/main.jsx`

### 1. 抽出 shell 颜色常量

在 `PinvouApp` 渲染附近或组件内部派生：

- `shellBg`
- `contentBg`
- `sidebarBg`
- `titlebarText`

建议不要大范围引入新 CSS 文件，先在当前 Tailwind/className 风格里收敛。

### 2. 外层根容器背景改为 shell 背景

当前根容器大致是：

```jsx
className={`flex flex-col h-screen ... ${activeTheme === 'dark' ? 'bg-[#131314]' : 'bg-white'}`}
```

建议改为：

```jsx
className={`flex flex-col h-screen ... ${activeTheme === 'dark' ? 'bg-[#131314]' : 'bg-[#F0F4F9]'}`}
```

这样 titlebar、侧边栏、圆角外露区域都有同一底色。

### 3. TitleBar 背景跟 shell 统一

当前 `TitleBar` 浅色已经是 `#F0F4F9`，深色是 `#131314`。需要保留这个方向。

后续如果要弱化重复品牌，可以另开一笔小改，但本轮圆角问题优先不动文案，避免扩大范围。

### 4. 主内容包一层全局 surface

当前主内容容器大致是：

```jsx
<div className="flex-1 flex flex-col relative min-w-0 overflow-hidden">
  ...
</div>
```

建议改为主题化 surface：

```jsx
<div
  className={`flex-1 flex flex-col relative min-w-0 overflow-hidden rounded-tl-[32px] ${
    activeTheme === 'dark' ? 'bg-[#0F1012]' : 'bg-white'
  }`}
>
  ...
</div>
```

注意点：

- 圆角必须加在全局主内容容器，不加在页面内部。
- `overflow-hidden` 可以保留，用来裁掉圆角内部背景。
- 如果某些页面需要自身滚动，内部滚动容器继续负责滚动。

### 5. flex 主区域不额外染白

`<div className="flex flex-1 min-h-0">` 可以保持透明，让根容器 shell 背景露出来。

如果需要明确，可加：

```jsx
className="flex flex-1 min-h-0 bg-transparent"
```

### 6. 侧边栏背景统一

当前侧边栏展开深色是 `#1E1F20`，收起深色是 `#131314`，浅色通过条件覆盖为 `#F0F4F9`。

建议本轮先保持现状，只确保浅色外层跟侧边栏一致。若深色圆角外侧色差明显，再考虑把展开态侧边栏也统一到 `#131314`，或把 shellBg 改成 `#1E1F20`。
