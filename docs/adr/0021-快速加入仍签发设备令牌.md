# 快速加入仍签发设备令牌

> 状态：已由 ADR-0022 取代。

本决策曾计划提供一个默认关闭的“快速加入”开关，让私网设备凭服务器地址直接领取只读令牌。产品验证后确认，这会把网络位置、加入方式和权限混成一个难以解释的开关，也绕开了成员审批，最终未作为正式产品能力保留。

ADR-0022 采用统一的加入申请模型：携带服务器身份和 CA 的分享连接负责定位服务并提交申请，不直接授予知识访问权；所有者批准后，每台设备才取得独立凭据。面向多人时使用默认二十四小时有效且可多人申请的分享连接，可按该连接显式启用“自动批准只读”，不再提供局域网发现、手动地址首次信任、全局快速加入状态、`lan-read` 产品入口或无申请的令牌签发接口。
