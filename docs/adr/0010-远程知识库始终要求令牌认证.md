# 共享知识库始终要求设备凭据

> 状态：设备独立凭据与服务端强制鉴权继续有效；加入方式与所有者入口由 ADR-0022 修订。

共享知识库不因客户端位于同一局域网或 Tailnet 就允许匿名访问。除不返回知识内容的最小服务信息外，浏览、检索、上传、更新、下载和删除均要求服务签发的设备凭据。网络可达性不能替代产品授权，客户端界面隐藏操作也不能替代服务端权限检查。

设备角色分为只读、内容管理和所有者。只读设备可以浏览、检索、查看来源并下载原始文档；内容管理设备可以维护知识集和文档；所有者设备在此基础上可以审批加入申请、管理成员和分享。主机安装、升级、停止、移除、恢复和所有者提升只允许由主机本机的系统授权通道执行，任何网络凭据都不能调用这些生命周期能力。

加入者通过默认二十四小时有效、可供多人提交申请的分享连接，或局域网附近发现提交独立申请。批准后，每台设备取得互不共享的随机凭据，Pinvou 只将秘密写入系统凭据库。所有者可以调整普通成员角色、撤销、恢复或永久移除设备；服务端每次请求都依据实时授权状态判定权限。

分享连接本身不包含知识访问凭据。默认仍需所有者批准；所有者可在创建某条分享连接时明确允许其有效期内自动批准只读申请。停止分享或到期只阻止新的申请，不影响已经批准的设备。
