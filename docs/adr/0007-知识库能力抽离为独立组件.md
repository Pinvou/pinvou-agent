# 知识库能力抽离为独立组件

远程知识库引入了桌面端与无界面服务器两个真实运行主体，因此将目前内嵌于 `pinvou3-tauri` 的通用知识库能力迁入父仓内独立的 `pinvou-knowledge` 包，而不放入 CodeWhale，也不让服务器反向依赖桌面 App。首期该包同时提供可复用 library 与 `pinvou-knowledge-server` binary：本地知识库由桌面端调用 library，远程知识库由桌面端通过网络调用 server；Tauri、会话、Agent 工具和界面适配仍由桌面端持有，待独立发布周期或依赖边界确有需要时再考虑拆分 library 与 server crates。
