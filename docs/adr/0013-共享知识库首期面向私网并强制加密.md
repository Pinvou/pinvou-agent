# 共享知识库首期面向私网并强制加密

共享知识库首期面向局域网与 Tailnet，不支持把服务端口直接暴露到公网。私网提供可达性和额外隔离，但不能替代设备授权。

服务首次创建时生成稳定的本机 CA，服务叶证书覆盖当前网络地址并可在地址变化后重新签发。分享连接携带该 CA；Pinvou 在发送加入秘密或设备凭据前固定并验证服务身份。根据 ADR-0022，附近发现和手动私网地址只提供可达候选，必须先通过宿主界面核对稳定 CA 派生的身份码，不能把同一条未认证连接返回的身份材料静默当成信任根。本机回环仅用于 root 所有的托管 helper 连接本机服务。除本机回环兼容入口外，新连接不接受明文 HTTP，旧 HTTP 配置只保留为可见迁移项且不会发送凭据。

普通局域网通过 mDNS 广播最小候选信息；候选必须经过无凭据服务探测和人工身份码核对，不能自动信任。Tailnet 不做自动扫描，只接受显式填写 `100.64.0.0/10` 地址或 `.ts.net` 名称并执行同样的身份核对。分享连接继续统一覆盖局域网、Tailnet、跨网段和群组分享。公网反向代理和公共服务目录不属于首期支持范围。
