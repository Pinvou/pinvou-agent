# 共享知识库首期面向私网并强制加密

共享知识库首期面向局域网与 Tailnet，不支持把服务端口直接暴露到公网。私网提供可达性和额外隔离，但不能替代设备授权。

服务首次创建时生成稳定的本机 CA，服务叶证书覆盖当前网络地址并可在地址变化后重新签发。分享连接和局域网发现携带该 CA；Pinvou 在发送加入秘密或设备凭据前固定并验证服务身份。手动输入地址时先执行不携带凭据的首次身份确认，再以返回的 CA 重新建立并校验连接。除本机回环兼容入口外，新连接不接受明文 HTTP，旧 HTTP 配置只保留为可见迁移项且不会发送凭据。

局域网发现只广播最小服务身份，不列出知识集、成员或文档，也不扫描 Tailscale 节点。Tailnet、跨网段和群组分享使用分享连接或手动 HTTPS 地址。公网反向代理和公共服务目录不属于首期支持范围。
