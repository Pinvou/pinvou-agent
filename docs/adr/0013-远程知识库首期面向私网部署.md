# 共享知识库首期面向私网并强制加密

共享知识库首期面向局域网与 Tailnet，不支持把服务端口直接暴露到公网。私网提供可达性和额外隔离，但不能替代设备授权。

服务首次创建时生成稳定的本机 CA，服务叶证书覆盖当前网络地址并可在地址变化后重新签发。分享连接携带该 CA；Pinvou 在发送加入秘密或设备凭据前固定并验证服务身份。根据 ADR-0022，首次加入不再通过附近发现或手动地址建立信任；本机回环仅用于 root 所有的托管 helper 连接本机服务。除本机回环兼容入口外，新连接不接受明文 HTTP，旧 HTTP 配置只保留为可见迁移项且不会发送凭据。

局域网、Tailnet、跨网段和群组分享统一使用分享连接，不广播服务发现，也不扫描 Tailscale 节点。公网反向代理和公共服务目录不属于首期支持范围。
