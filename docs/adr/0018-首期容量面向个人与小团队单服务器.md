# 首期容量面向个人与小团队单服务器

首期远程知识库面向个人及小团队的单服务器共享场景，不承诺企业级多节点集群、分片或横向扩容。设计目标为单服务约 20 台已授权设备、1 万份源文档或 100 万个文档分段，并覆盖多客户端同时检索与后台导入的竞争场景；这些数字是待基准验证的工程目标，不是已证明的容量保证，也不是产品硬配额。在真实 BGE-M3 向量维度与参考硬件上完成 100 万分段、多客户端并发的可重复基准之前，文档和界面不得宣称已达到该规模。性能结果必须注明参考硬件、模型和数据集；超出目标后的实际瓶颈由基准测试决定，不能预先用外部基础设施增加首期部署负担。

共享服务使用持久化的局部敏感哈希向量桶缩小语义候选集，再对候选向量做精确余弦排序；全文结果与向量结果仍按倒数排名融合。旧数据库升级后在后台分批补建桶签名，未补建的分段继续参与精确扫描，因此迁移期间不要求停服重建，也不会漏掉旧内容。该索引控制单次检索的向量读取量，但不替代上述真实规模基准。
