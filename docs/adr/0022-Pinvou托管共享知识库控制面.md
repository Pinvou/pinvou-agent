# Pinvou 托管共享知识库控制面

> 状态：已接受。取代 ADR-0012 与 ADR-0021，并修订 ADR-0010 的入网方式和 ADR-0017 的管理入口。

共享知识库不再作为需要用户另行部署和打开 Web 后台的服务器产品，而由 Linux 版 Pinvou 在当前设备上一键创建并持续托管。Pinvou 安装包携带匹配版本的后台服务组件，创建、成员、分享、模型、备份、升级和恢复全部使用 Pinvou 原生界面；浏览器管理页、所有者密码、Cookie 会话和初始化密钥退出产品。服务关闭 Pinvou 后继续运行，主机重启后自动恢复；一台主机首期只持有一个共享知识库服务，服务内仍可建立多个知识集。

主机 Pinvou 通过仅限本机且需要系统管理员确认的控制面完成安装、升级、停服、移除、迁移、恢复和本机接管，网络管理 API 永远不能执行这些主机生命周期操作。设备先通过局域网附近发现或默认二十四小时有效、可多人使用的分享连接提交加入申请，批准后取得独立设备凭据；分享连接默认不授予访问权，所有者可以显式开启有效期内自动批准只读。现有成员只能由主机提升为所有者设备，所有者设备拥有完整内容管理与远程治理能力，但不能提升其他所有者或控制主机生命周期。

创建共享知识库不会自动暴露本地知识，用户只能显式将本地知识集发布为独立的共享副本。主机自动连接自身共享知识库，但不会自动把知识集挂载到会话。本地知识库和共享知识库复用同一份经过版本与摘要校验的 BGE-M3 模型；服务程序随 Pinvou 分发，模型按需下载。共享访问默认使用由稳定服务器身份保护的加密连接。分享连接可以携带多个局域网或 Tailnet 私网候选地址，并直接提供待固定的服务器身份与 CA。局域网发现和手动私网地址也可作为首次入口，但只产生未受信候选；客户端必须在发送设备凭据前展示稳定 CA 派生的身份码，由用户与宿主界面核对后固定身份。Tailnet 只允许手动输入，不自动扫描。

卸载 Pinvou 默认保留后台服务和数据，移除共享知识库是独立的高风险操作。备份与恢复属于 Pinvou 所有者控制台：本机恢复使用系统安全存储中的密钥，跨主机恢复才需要另存的恢复码；迁移恢复知识内容但创建新的服务器身份和成员授权。桌面应用升级不会静默替换后台服务，主机用户明确触发服务升级，升级保留身份、数据和授权并在失败时回滚。

这一选择牺牲纯命令行服务器作为普通用户入口和浏览器通用管理便利性，换取单一产品体验、清晰的本机安全边界与可恢复的一键托管。首版创建能力仅面向能够运行 Pinvou 图形界面的 Linux 主机；命令行部署保留为开发和高级运维能力，Windows 与 macOS 首期只能加入已有共享知识库。
