# 远程知识库采用单机自包含部署

> 状态：单机自包含和受管数据目录继续有效；Web 后台与模型目录边界由 ADR-0022 修订。

首期 `pinvou-knowledge-server` 采用单机自包含部署：一个服务程序管理 Web 后台、API、任务处理、元数据、全文与向量检索以及受管源文档，持久状态集中在一个明确的数据目录，embedding 模型也由服务器本机持有。正常安装和运行不得要求用户另行部署 PostgreSQL、Qdrant、Redis 或其他网络状态服务；具体的进程内索引实现可以演进，但不能破坏数据导出与重建能力。服务器备份和迁移以数据目录及配套清单为边界，并应提供一致性备份流程，而不是要求用户理解内部数据库文件。未来若实际容量超过单机目标，可以新增外部存储适配，但不作为社区版首期可用闭环的前置条件。
