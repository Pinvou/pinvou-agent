# Web 后台作为服务器管理主入口

> 状态：已由 ADR-0022 取代。

`pinvou-knowledge-server` 自带浏览器 Web 管理后台，并以它作为首次配置、模型部署、访问授权、备份和诊断的主要入口；管理员也可以在其中管理知识集与文档。Pinvou 桌面应用承担远程连接、日常知识使用，以及与访问级别相符的内容管理：具有管理访问的使用者可以在统一“知识库”页面的“远程知识库”分区创建知识集并上传、更新或删除文档，只读使用者不能执行这些操作。日常内容维护不要求使用者进入服务器后台，服务器存储路径、模型、授权和运维配置也不下放到桌面端。

首期只有初始化时建立的单一服务器所有者可以登录 Web 管理后台。管理访问只代表知识内容的维护权限，不授予模型、存储、设备授权、备份、恢复或服务器诊断权限，也不能用于登录后台。首期不引入多管理员账号、角色继承或账号找回系统；服务器所有者凭证的重置属于只能在主机本地触发的受控恢复操作。

首次启动由 Web 向导完成服务器所有者凭证、存储和 embedding 模型等配置，但进入向导前必须提交服务器启动时随机生成并只交给部署者的一次性初始化密钥，不允许同网段首位访问者直接认领管理权。初始化成功后，初始化密钥和公开初始化入口永久失效；密钥遗失或确需重置时，只能通过服务器本机的受控恢复流程触发。项目不把 CLI 或手工编辑配置文件作为普通用户完成部署或管理的必经步骤，命令行仅可保留进程启动、开发调试和 Web 后台不可用时的灾难恢复能力。
