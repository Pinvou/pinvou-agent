# 模型服务错误展示

主对话、原生代码会话、子智能体记录及桌宠共用模型服务错误分类与脱敏。模型调用的余额、额度、鉴权、限流和网络等错误以简体中文、英文、日文展示；普通工具与各连接器（如飞书、企业微信、钉钉）错误不因单独出现 HTTP 状态码就被归类为模型服务错误，原始文本兜底仍先脱敏。

可恢复错误显示重试提示；权威终态到达后更新同一错误提示。只有实际写入带错误的终态记录，才由时间线错误卡替代气泡；没有终态记录时保留可见提示。成功恢复后隐藏失效的重试提示，不同会话和回合不互相去重。权威 `turn_id`、会话隔离和已有任务生命周期保持不变。

托管在「官方 API」分组的模型服务（provider kind `official_api`，见 `pinvou3-app/src/features/settings/model-catalog.js`）保持只读：鉴权错误引导在模型设置中重新填写 API Key，限流、服务不可用或未知错误引导稍后重试或切换其他可用模型（受控文案见 `pinvou3-app/src/shared/model-service-errors.js`）。会话模型优先于全局默认模型；历史错误中明确的供应商信息优先于当前模型，已保存的结构化错误保留原提示。原生代码会话只使用归属匹配的已加载原生控件模型，不使用聊天会话的模型、默认模型或有效配置；切换或加载中、后台会话均不借用其他会话的模型归属。

错误文本与技术详情仅用于已有错误展示路径，不新增遥测事件或上传字段，不上传原始错误。凭据先经 Rust 脱敏，再经过前端展示层脱敏；不改变已有受控埋点开关、事件分类和终态去重。

回归入口：`npm --prefix pinvou3-app run test:chat-error-isolation`，以及代码原生时间线与会话时间线相关测试。
