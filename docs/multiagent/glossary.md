# pinvou3 多智能体术语表

本文定义 pinvou3 桌面实例内多智能体协作使用的统一术语；桌面实例、Session、产物等共享概念沿用 `docs/remote-control/glossary.md`。

## 术语

**多智能体模式（Multi-agent Mode）**：
会话内的一项可开关能力，开关位于输入框的模型选择器下方，每个会话记住自己的开关状态。开启后本会话获得主动委派能力：模型可按任务形态派出子智能体（或不派）。它不是一种会话类型——任何普通对话都可以开启。
_Avoid_: 多智能体对话、工作流运行、专属会话

**主动委派（Delegation）**：
多智能体模式开启后注入给模型的行事方式：单个独立任务派一个子智能体，多阶段任务派一群子智能体由父模型亲自协调汇总（agent 集群），简单任务自己直接做。委派与否由模型判断，用户不需要理解派发协议。
_Avoid_: 编排、调度

**子智能体（Subagent）**：
一次委派派生出的执行实例，有自己的完整对话记录与运行状态，在消息流中以专家卡片形式可见、可点开查看。角色/专家卡是它的身份来源，子智能体是"这次出勤"的实例——同一角色可同时有多个实例。
_Avoid_: 工位、子任务

**执行记录（Transcript）**：
子智能体面板展示的内容：该实例的完整思考、工具调用与结果，形态像普通对话但**只读**。它不是第二个聊天入口——用户与子智能体的一切互动（追问、打断、取消）都通过父对话表达，由父模型转达。
_Avoid_: 子代理聊天、抽屉

**角色（Role）**：
可被派活的一种身份，规定职责与人设。内置四角色（调研/规划/执行/审查）与专家池入册的专家卡都是角色；专家池只负责身份、人设与头像，不参与调度实现。
_Avoid_: Agent

**角色名册（Roster）**：
多智能体模式开启时装配进会话工作区的角色集合，供模型按名字派工。专家池的用户自建卡自动入册。
_Avoid_: 团队、卡池

**只读/执行（权限档）**：
即会话既有的 Plan / Yolo 两档，多智能体不新增权限概念。Plan（只读）下委派限于调研/审查类子智能体（保留联网，不改本地文件），产出方案待用户接受；Yolo（执行）下子智能体继承会话的完整工具与审批策略。
_Avoid_: 工具白名单、专家权限

**编排图（Plan）**：
底座 `workflow` 工具的结构化输入。该工具与主线一致对所有会话可用，但委派提醒不教学、不推荐——底座对 read_only 子任务的工具钳制与阶段结果不传递两处已知限制未修（真机事故根因），多阶段任务默认由父模型用 agent 集群亲自协调。
_Avoid_: 流程、DAG、路由表

## 已退役术语

**工作流运行（Workflow Run）**（2026-07-31 退役）：原指"一次多智能体任务=一场专属会话+运行台账"。多智能体改为会话内开关能力后，不再存在独立的"运行"实体；运行台账随之退役。
