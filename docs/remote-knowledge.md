# 共享知识库

> 共享链接可以直接固定服务器身份与 CA；局域网发现和手动私网地址只产生“待核对”的可达候选，用户核对宿主身份码后才会固定 CA、提交加入申请。网络可达性不等于服务器身份或设备授权。

共享知识库是 Pinvou 自带的团队知识托管能力。Linux 用户可以在 Pinvou 的知识库页面直接创建一台持续运行的共享主机；Windows 和 macOS 首期可以加入已有主机。普通用户不需要终端、SSH、浏览器后台、管理员密码或初始化密钥。

## 创建与加入

- Linux 主机选择“在本机创建”，确认一次系统授权后，Pinvou 安装与当前客户端匹配的 systemd 服务并自动登记为所有者。
- Pinvou 打开加入弹窗时自动发现同一局域网内的共享主机，也接受手动输入局域网地址；Tailnet 地址只允许显式输入，不扫描 Tailscale 节点，也不依赖 Tailscale CLI。
- 附近发现和手动地址不得直接建立信任。客户端先做不携带任何设备凭据的服务探测，显示由稳定 CA 派生的宿主身份码；用户与宿主界面核对一致后才固定身份并提交待审批申请。身份变化时必须阻止连接。
- 共享链接携带服务器身份、CA、申请凭据和一个或多个局域网/Tailnet 候选地址，可以跳过人工身份码核对；客户端仍会逐一验证候选地址，且不会仅因地址可达而授予访问权。
- 分享连接默认二十四小时有效，可以供多人提交申请。默认由所有者逐个批准，也可为当前分享显式开启自动批准只读。
- 每台获批设备拥有独立凭据。分享连接泄露不会直接获得知识访问权，停止分享不撤销已经批准的成员。

## 内容与权限

服务内可建立多个知识集。只读成员可以检索、查看来源和下载文档；内容管理员可以创建知识集、添加文件或文件夹、更新和移入回收站；所有者还可以管理分享、申请和成员。

创建主机不会自动公开本地知识。用户通过“发布到共享知识库”选择本地知识集和原始文件，确认后生成独立共享副本；发布后两份内容不自动同步。同一知识集再次添加内容完全相同的文档时复用已有记录，不重复存储和索引。

删除内容先进入三十天回收站。回收站集中展示已删除知识集和文档，支持恢复或在二次确认后永久删除。永久删除同时清理数据库记录、索引和托管源文件。

## 文档解析与分块

共享知识库拒绝导入私钥等敏感密钥材料，并支持 UTF-8、UTF-16 和 GB18030 文本。PDF 使用 `pdftotext`，Office 文档优先使用 `pandoc`，不支持的 Office 格式回退到 LibreOffice；演示文稿由 LibreOffice 转为 PDF 后再提取文本。缺少外部解析器时，单份文档会显示明确失败原因，不影响其他文档。

本地知识库与共享知识库复用同一套分块逻辑：优先在目标长度 60% 之后寻找句号、问号、感叹号或换行等边界；找不到合适边界时才按最大长度截断，并保留固定重叠区。这样可以减少跨句切断，同时保证超长文本稳定前进。

## 模型、升级与备份

本地与共享知识库复用同一份经过固定 revision 和逐文件摘要校验的 [BGE-M3 模型](knowledge-model.md)。服务缺少模型时可以保存文档，但检索在模型与索引就绪后才开放。

客户端升级不会静默替换正在运行的共享服务。主机用户在 Pinvou 中明确触发服务升级；升级失败自动恢复上一版二进制。关闭或卸载 Pinvou 默认保留服务和数据，移除主机是单独的高风险操作。

备份由 Pinvou 创建一致性的加密包，包含数据库与托管源文档，不包含可重新下载的模型。同机恢复使用系统凭据库中的本地密钥并保留服务身份、CA 和成员；跨主机恢复需要单独保存的恢复码，只迁移知识内容，并生成新的服务身份、CA 和成员授权。

## 网络安全

所有网络访问都使用 HTTPS，并在发送加入秘密或设备凭据前固定服务 CA。新连接不接受私网明文 HTTP；旧 HTTP 配置只显示迁移提示且不会发送凭据。首期只支持局域网和 Tailnet，不支持直接公网暴露。
