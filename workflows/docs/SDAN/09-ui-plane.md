# 09 · 用户界面平面（卡片流）

> 架构层文档 · 通用 · **本篇取代原「品悟网关」设计**（白浪 2026-05-29 拍板）

## 决策：取消对话型品悟网关，工作流用户界面 = 纯卡片流

工作流里**不再有「会聊天的品悟」这个角色，也没有聊天窗口**。用户直接面对**卡牌组 + DAG**，外加底部的**卡片交互区**。

### 为什么（第一性）

1. **框架硬约束**：面向用户的对话只能由 Engine（顶层 turn loop）承载；SubAgent 当不了用户的直接对话方。把「工作流大脑」做成一个对话型 LLM，就得占着 Engine 当对话方。
2. **会被带歪**：通用助手系统提示词（`instructions.md`）通篇是「直接干活 + 用全套工具 + 每轮必推进」。硬塞一个监工/网关人格进去，它会去试自己没有的工具、瞎读文件硬凑、甚至幻觉进度——拿提示词去拗它是逆风拔河（实测坑：广告全套工具 → 死循环）。
3. **真相源原则**：进度的真相在 🧠State 里；UI 直读 State 就是进度，**让一个 LLM 去转述真相只是多一层不可靠中介**。
4. **结论**：拿掉对话型品悟，等于拿掉最弱、最易出错的一环。控制核仍唯一 = Router；用户面对的是**工作流的真实状态本身**，不是某个 LLM 对它的叙述。

## 用户界面 = DAG + 四类卡片（全部直连，不经对话型 LLM）

| 界面元素 | 数据来源 | 说明 |
|---|---|---|
| **DAG / 节点卡牌组（进展）** | UI 直读 🧠State（已有 `read_full_agent_state`） | 节点状态实时反映 = 进展报告本身，零 LLM、不会幻觉进度 |
| **收集类 SubAgent 卡片（工作流→要信息）** | 节点级 `request_user_input`（见 `04`、`11#6`） | 底座已接线（`tx_user_input` → GUI 卡片）；某角色要信息时弹卡片问用户 |
| **系统通知卡片（blocked 等）** | 工作流系统直发（见 `11#3`、`02` blocked 节） | 如「⚙️ 卡在 X，原因 Y」，独立样式 |
| **裁决建议卡片（soft 提醒）** | soft 裁决器（见 `05`） | **不阻断**，仅告知，如「质检建议：第 3 页配色偏暗」 |

> **卡片叠放**：客户卡片多了，像扑克牌一样**错开叠在一起**；底部交互区维护一个卡片队列。

## 启动

工作流由 **UI 启动动作**（用户在卡牌组点「开始」）触发 Router 的 `on_start`（见 `02`）——不再经任何品悟 tool。

## 用户干预 = 改控制平面（推迟）

- **没有自然语言干预入口**（不设聊天框、不设 inject 对话）。
- 用户要干预，**直接改控制平面**：编辑 SubAgent 卡牌 / 路由表（`route_table`）。
- 现阶段**推迟**：需要可编辑的卡牌/路由表 UI + Router 运行时重读改动。承 `11#8`「用户主动变更推迟」。

## Engine 的去向：降级为沉默宿主（**不是删掉**）

⚠️ 框架硬约束：**SubAgent 必须跑在某个 Engine 里**——Engine 持有 LLM client、SubAgent manager、事件通道、以及把 `request_user_input` 变成 GUI 卡片的 `tx_user_input`。所以 Engine **不能删**。

变的是：Engine **不再有对话人格、不再有聊天界面** → 降级成**沉默的运行时宿主**，由 Router/Harness 通过 `Op::SpawnSubAgent` 驱动，只负责 host 角色 SubAgent + 把节点卡片事件透出到 UI。

> 落地细则（白浪 2026-06-04 拍板）：工作流宿主 session **不进 chat 会话列表、不抢 active 会话**——chat 与工作流彻底分开；宿主 session 仅作 SubAgent 运行时存在，对用户不可见。

## 被本决策取消的东西（原 09 内容作废）

- ❌ 「品悟工作流 / Pinvou Workflow」独立角色 + v1 提示词
- ❌ 对客户的「自由对话」线 / 项目经理式对话
- ❌ `query_progress` 的**对话用途**（读 State 的能力本身仍由 UI/Tauri 命令直接用，但不再有对话型品悟去调它）
- ❌ 对话框「品悟消息 vs 系统消息」双消息源（已无对话框）

> 仍保留（本就与卡片流一致）：节点级 `request_user_input` 卡片（`04`）、系统直发卡片（`11#3`）、blocked 逃生（`02`）。
